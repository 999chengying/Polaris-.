# Polaris V4-04：具身双向车道：连续状态空间的编解码与物理控制映射

## 一、本文解决什么问题

纯整数心智引擎在内部构建了完美的离散拓扑，但具身智能不能只活在抽象拓扑里。系统必须能够接收连续的物理感知，并最终输出连续的物理动作。本文构建了**“双向车道（Bidirectional Bridge）”**，实现了从连续输入到离散小模运算，再无损解码回连续控制信号的全链路闭环。

## 二、双向车道的核心架构

1. **编码器（Encoder）**：将连续的物理量转换成连续值小模三元组 (d1, d2, d3)。保留千分位级的物理精度。
2. **核心拓扑层（Core Topology）**：在离散的模 10 空间内，利用三维内容路由与历史动量进行纯整数演化。
3. **解码器（Decoder）**：将演化后的离散小模还原为连续实数（d1*100 + d2*10 + d3 / 1000）。
4. **物理映射（Action Mapper）**：将 [0.000, 0.999] 空间线性拉伸至 [-1.0, 1.0] 的具身控制信号空间，直接对接电机驱动。

## 三、具身行为特性

- **平滑感知**：通过低阶路由输出控制信号（如 -0.240 与 +0.120），代表常规环境下的微调与平稳移动。
- **紧急动作**：特征突变触发 Z 轴唤醒，输出极限控制信号（如 -0.996 与 +0.846），对应急刹车与满负荷扭矩输出。
系统不仅实现了纯整数无损运算，还能根据输入特征的变化，产生极具方向性的物理控制。

## 四、代码实现

    def encode_continuous(val):
        """连续值转小模"""
        s = f"{val:.3f}".split('.')
        return (int(s[1][0]), int(s[1][1]), int(s[1][2]))

    def decode_to_continuous(state):
        """小模转连续值"""
        d1, d2, d3 = state
        return (d1 * 100 + d2 * 10 + d3) / 1000.0

    def map_to_action(cont_val):
        """映射为具身控制信号 (-1.0 ~ 1.0)"""
        return (cont_val * 2.0) - 1.0

    # 测试用例
    state = encode_continuous(3.141)
    cont_val = decode_to_continuous(state)
    action_signal = map_to_action(cont_val)
