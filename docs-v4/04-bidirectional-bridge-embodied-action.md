# 具身双向车道：小模编解码与连续物理控制输出

## 一、这篇解决什么问题

纯整数心智引擎在内部构建了完美的离散拓扑（如七炉阵、差1/2/5墙），但具身智能不能只活在自己的拓扑里。系统必须能够**“接收连续的物理感知”**，并最终**“输出连续的物理动作”**。本文构建了 Polaris V15 的双向车道，实现了从连续输入到离散小模运算，再无损解码回连续控制信号的全链路闭环。

## 二、双向车道的核心机制

1. **编码器（Encoder）**：
   将连续的物理量（如感知电压）转换成 V2 的连续值小模三元组 `(d1, d2, d3)`。保留了千分位级的物理精度，彻底杜绝量化截断。
2. **全息七炉阵（Core）**：
   在离散的模10空间内，利用三维内容路由（X/Y/Z）与历史动量牵引，进行纯整数的拓扑演化。
3. **解码器（Decoder）**：
   将演化后的离散小模 `(d1, d2, d3)` 还原为连续的实数（`d1*100 + d2*10 + d3 / 1000`）。
4. **物理映射（Action Mapper）**：
   将 `[0.000, 0.999]` 连续值空间，线性拉伸至 `[-1.0, 1.0]` 的具身控制信号空间。

## 三、实验数据与具身行为对账

*   **平滑感知（输入 3.141, 3.149）**：
    路由至 X轴、Y轴，输出控制信号为 `-0.240` 与 `+0.120`。代表机器人在常规环境下的微调与平稳移动。
*   **紧急动作（输入 3.172, 3.279）**：
    由于特征突变，Z轴（动作轴）被唤醒。输出控制信号分别达到 `-0.996`（急刹车）与 `+0.846`（满负荷反向冲刺）。

**结论**：系统不仅实现了纯整数的无损运算，还能根据输入特征的细微变化，产生极具爆发力与方向性的物理控制输出。
