# Polaris V4-03：三维混合专家系统（3D-MoE）：连续小模与纯整数内容路由

## 一、本文解决什么问题

在传统的大模型混合专家系统（MoE）中，路由网络通常依赖高维浮点向量与 Softmax 激活函数，不仅计算昂贵，且极易因为浮点截断导致“特征量化丢失”，或因缺乏历史上下文而陷入“路由死锁”。
本文提出一种**“三维纯整数 MoE 架构”**。系统通过连续值小模输入保留高维精度，利用三维内容寻址（Content-Addressable）进行纯整数路由，并引入动量记忆池（Momentum Memory）实现历史状态牵引，彻底解决了模式坍塌与长程一致性难题。

## 二、核心机制

### 1. 连续小模输入（规避量化截断）
外部连续浮点特征（如 3.141）被无损编码为三元组 (d1, d2, d3)，利用级联进位完美保留物理细节。在路由打分与传播中，始终保持纯整数状态，杜绝浮点漂移。

### 2. 纯整数内容路由（取代硬编码）
摒弃传统硬编码的奇偶判断，为 X轴（逻辑）、Y轴（感知）、Z轴（动作）分别设定特征偏好权重。输入状态与三轴权重进行纯整数点乘（Mod10），得分最高的轴自动被唤醒，实现真正的“内容寻址”。

### 3. 动量记忆与历史牵引（防死锁）
每个专家节点拥有一个“动量记忆池”。算子 k 不再固定，而是受历史动量牵引：
k = (输入 + 历史动量 + 空间偏置) % 10
动量更新采用纯整数衰减公式（当前状态占 7 成，历史占 3 成），彻底杜绝浮点污染，并自带防死锁锚点（5）。

## 三、代码实现

    def integer_moe_router(state, axis_weights, memory_pool):
        """
        三维 MoE 纯整数路由。
        """
        d1, d2, d3 = state
        best_axis = 'X'
        best_score = -1
        
        # 1. 纯整数内容路由打分
        for axis, w in axis_weights.items():
            score = (d1 * w[0] + d2 * w[1] + d3 * w[2]) % 10
            if score > best_score:
                best_score = score
                best_axis = axis
                
        # 2. 提取对应专家的动量记忆
        history_k = (memory_pool[best_axis] + 5) % 10 or 5
        
        # 3. 推演算子 (基于输入与历史动量)
        k = (d1 + history_k) % 10
        if k == 0: k = 5
        
        # 4. 状态演化
        next_state = (
            (d3 * k + 5 + 1) % 10,
            (d2 * k + 5 + 3) % 10,
            (d1 * k + 5 + 5) % 10
        )
        
        # 5. 动量衰减更新
        current_sum = sum(next_state) % 10
        memory_pool[best_axis] = (current_sum * 7 + memory_pool[best_axis] * 3) // 10
        
        return next_state, best_axis
