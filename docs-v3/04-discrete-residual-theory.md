# Polaris V3-04：离散残差定理：基于模10对合映射的零漂移网络架构

## 一、本文解决什么问题

在深度神经网络（ResNet/Transformer）中，残差连接 y = x + f(x) 是解决梯度消失的基石。然而，底层浮点加法会导致随着层数加深的“数值漂移（Float Drift）”，必须依赖高昂的 LayerNorm 来强行拉回分布。本文提出一种**“离散残差定理”**，基于纯整数模10空间的对合映射（Involution），不仅实现了零浮点漂移，还彻底消除了对均值方差归一化的依赖。

## 二、核心机制：模10对合映射

传统残差是无界的浮点加法，而 Polaris 定义了一种离散映射算子 R5：
R5(x) = (x + 5) mod 10
网络的前向传播被定义为：
H_out = R5(H_in + f(H_in))

### 1. 对合性定理（Involution Theorem）
在模10空间中，算子 R5 是二阶对合的，即 R5(R5(x)) = x。
证明：(x + 5 + 5) mod 10 = (x + 10) mod 10 = x。
这意味着，无论网络有多少层，只要经历了偶数次相变，状态必然精准归位。系统具备绝对的零漂移特性，彻底消除了深层网络的精度焦虑。

### 2. 硬边界归一化（Hard Boundary Normalization）
传统 LayerNorm 依赖整个 Batch 的均值和方差来缩放特征，计算昂贵。而“离散残差”只需通过模10取余，就能把任意发散的特征瞬间锚定在 [0, 9] 的合法拓扑边界内，有效防止了梯度爆炸。

## 三、代码实现

    def discrete_residual(x, f_x):
        """
        离散残差连接：执行对合映射
        """
        return (x + f_x + 5) % 10

    # 测试对合性
    x_initial = 3
    # 第 1 层
    h1 = discrete_residual(x_initial, 2) # (3+2+5)%10 = 0
    # 第 2 层（假设此时 f_x 刚好为0，验证对合回归）
    h2 = discrete_residual(h1, 0)        # (0+0+5)%10 = 5
    # 第 3 层（再经过一次）
    h3 = discrete_residual(h2, 0)        # (5+0+5)%10 = 0

## 四、结论

| 验证项 | 结果 |
|---|---|
| 对合性 | R5(R5(x)) ≡ x (mod 10) |
| 零漂移 | 纯整数运算，无浮点误差累积 |
| 归一化 | 用硬边界截断替代浮点方差计算，算力极低 |
