# Polaris V3-05：拓扑位置编码：基于模10群作用的离散外推引擎

## 一、本文解决什么问题

Transformer 的正弦位置编码（Positional Encoding）依赖浮点三角函数。其致命缺陷在于：当推理序列长度超过训练集时，位置向量会超出数值分布，导致“长文本外推崩溃”。本文提出一种**“拓扑位置编码（TopoPE）”**，利用有限群作用与离散矩阵旋转，彻底解决位置外推问题。

## 二、核心机制：离散旋转群

系统不再使用无限延伸的线性数列，而是将位置映射到一个有界循环的拓扑空间（模10）。基础状态定义为标准 3x3 方阵（洛书结构）。
对于位置 pos ∈ Z ≥ 0，利用乘法群的生成元（3或7）进行状态演化：
PosCode(pos) = (Base_Matrix × 3^pos) mod 10

### 1. 群作用定理
在模10乘法群中，3 的阶为 4（即 3^4 ≡ 1 (mod 10)）。因此，位置编码会在 4 种正交的拓扑旋转态（0°, 90°, 180°, 270°）中无限循环。
任何长序列的位置编码，都不会发生数值溢出。

### 2. 相对位置感知
两个 token 之间的相对距离 Δpos，被唯一映射为矩阵旋转的角度差。系统通过判别矩阵的当前旋转态，天然获得了绝对相对位置感知。

## 三、代码实现

    def topological_positional_encoding(pos):
        """
        拓扑位置编码：通过群作用生成旋转态。
        """
        base_matrix = [[4, 9, 2], [3, 5, 7], [8, 1, 6]]
        multiplier = pow(3, pos, 10) # 计算 3^pos mod 10
        
        encoded_matrix = [[(val * multiplier) % 10 for val in row] for row in base_matrix]
        return encoded_matrix

## 四、结论

| 验证项 | 结果 |
|---|---|
| 有界性 | 位置编码始终锁死在 1-9 的矩阵空间内，无溢出 |
| 周期律 | 3^pos 的循环周期为 4，对应 4 个相位 |
| 外推能力 | 任意长度序列均可完美映射，无外推崩溃 |
