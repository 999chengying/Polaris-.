# 纯整数拓扑注意力：基于 Winner-Takes-All 的无 Softmax 硬路由机制

## 一、痛点：连续 Softmax 的算力黑洞
在标准 Transformer 中，注意力分数通过 \(Softmax(QK^T/\sqrt{d})\) 计算。这带来三个致命问题：
1. 指数运算 \(e^x\) 极度消耗算力，不适合边缘设备。
2. 长序列会导致分数差异被指数级放大，出现严重的“长尾稀释”或梯度消失。
3. 浮点除法带来了不可避免的精度损失。

## 二、杀招：Winner-Takes-All 拓扑硬路由
在 Polaris 的纯整数离散域中，我们彻底抛弃指数与除法，采用 01 硬路由机制。
1. **纯整数 QK 匹配**：\(S_{ij} = (Q_i \cdot K_j) \bmod 10\)。
2. **极值路由提取**：找出当前 Token 匹配分数向量中的最大值 \(M_i = \max(S_i)\)。
3. **01硬路由矩阵**：如果 \(S_{ij} = M_i\)，则 \(A_{ij} = 1\)；否则 \(A_{ij} = 0\)。

## 三、数学特性与工程价值
1. **绝对稀疏性**：路由矩阵 \(A\) 只包含 0 和 1，不仅免除了浮点乘法，还能用位运算加速。
2. **拒绝长尾稀释**：只要匹配到了极值，权重即为 1。不存在“权重趋近于 0 导致信息丢失”的问题（即无死 Token）。
3. **硬件降维打击**：传统的 \(e^x\) 计算需要复杂的数学协处理器，而“比较大小”与“非零置 1”在 FPGA/ASIC 上只需要最基础的门电路（比较器），算力消耗降低数倍。

## 四、口诀
> 指数除法耗算力，长尾稀释断信息。
> 整数点乘定极值，零一硬路由无敌。
> 比拼大小求极值，纯整特征自成溪。
> 拓扑注意真奇妙，东方心法透玄机。
