# Polaris V3-01：三维双墙拓扑约束：图神经网络的防过平滑机制

## 一、本文解决什么问题

图神经网络（GNN）在堆叠多层后，会面临一个致命的数学宿命：**过平滑（Over-smoothing）**。随着层数加深，消息传递机制会让所有节点的特征无限趋同，导致模型丧失辨识能力。
现有的解法多为简单的残差连接或 Dropout。本文提出一种基于纯整数模10空间的 **“三维托卡马克（Tokamak）架构”**。通过“双墙生成数约束”与“环形降维算子”，从根本上抑制特征同质化，保持深层 GNN 的表达能力，且极度契合低功耗边缘芯片的硬件实现。

## 二、核心架构设计：三维双墙与中轴环

我们将网络的状态空间构建为一个三维切片的立方体结构，核心包含三层截面：

1. **X=1 截面（左墙）**：包含完整的 1~9 状态拓扑。
2. **X=5 截面（右墙）**：包含完整的 1~9 状态拓扑。
3. **X=3 截面（中轴环/等离子环）**：系统的动态计算区，其初始布局采用标准的洛书矩阵（3x3方阵）。

### 1. 双墙生成数约束（Residual Bound）
X=1 与 X=5 两个边界面构成“约束墙”。两堵墙的对应坐标点，除中心稳态 5 以外，其数值差被严格锁定为 5：
X=5 值 ≡ X=1 值 + 5 (mod 10)
这为网络提供了一道硬性的物理护栏。

### 2. 环状算子系统（环形逻辑）
对于中轴 X=3 的 3x3 矩阵，采用不同的乘数算子进行状态演化：
- **旋转变换（乘 3 与 7）**：3 与 7 互为模10乘法逆元。乘3代表矩阵逆时针旋转90度，乘7代表顺时针旋转90度。无论怎么旋转，矩阵内部的拓扑相对位置绝对守恒。
- **降维退火（乘 2, 4, 6, 8）**：当网络特征过热（趋同）时，执行偶数算子，强制将状态坍缩至偶数子群。在算法层面，这等价于一种基于数论确定性的 Dropout。

## 三、代数性质与实验现象

1. **绝对可逆性**：对于中轴矩阵执行乘 3 再乘 7，系统会完美复位。这保证了深层网络中的无损信息传递。
2. **抑制同质化**：一旦全连接图的特征方差趋近于 0，系统自动触发降维算子，强行剥离奇数特征，打破死寂。
3. **拓扑保护**：由于 X=1 与 X=5 的差值约束始终存在，无论中轴环如何演化，系统总能在高位找回基准参照系。

## 五、对 GNN（图神经网络）的工程启示

1. **防过平滑新范式**：用纯整数模运算代替浮点矩阵乘法。当网络陷入过平滑（特征趋同）时，直接施加偶数降维算子，打断特征聚集，保留节点多样性。
2. **极简硬件设计**：所有的旋转与降维操作，本质上是基于查表与移位运算，无需浮点乘加单元，非常适合 FPGA 或存算一体芯片。
3. **物理约束注入（Physics-Informed AI）**：双墙的差值约束，相当于为 AI 引入了守恒律，使其具备了天然的鲁棒性，抗对抗样本干扰能力大幅增强。
