# Polaris V3-03：TokamakConv：基于双墙拓扑约束与位置偏置的防平滑图卷积层

## 一、本文解决什么问题

深层图神经网络（GNN）普遍面临“过平滑（Over-smoothing）”问题：随着层数加深，所有节点的特征无限趋同，导致模型丧失辨识能力。现有的解法（如残差连接、Dropout）往往依赖于浮点随机性。本文提出 **TokamakConv** 图层，通过纯整数的“双墙差值约束”与“节点级位置偏置”，在代数层面强制打破特征同质化，实现防过平滑与防幻觉的统一。

## 二、核心架构设计

### 1. 双墙差值约束（Dual-Wall Bound）
隐藏层特征被分为两个通道：
- 通道 0（基准墙 X=1）：保存主特征。
- 通道 1（约束墙 X=5）：强制等于 `(通道 0 + 5) mod 10`。
无论网络多深，两路通道的差值永远被锚定在 5，为深层网络提供绝对的残差基准，防止浮点误差积累。

### 2. 过平滑监测与确定相变（Deterministic Phase Transition）
每一层前向传播后，系统计算通道 0 特征的方差（Variance）。
- **若方差 < 阈值**（特征严重同质化）：触发干预算子。
- **节点级位置偏置（Node-level Positional Bias）**：为了彻底打破全局同构，干预算子必须结合节点的空间拓扑（如节点索引 i）。执行公式：`val = (val × k + i) mod 10`。此扰动强制将相同的数字拉开，瞬间逆转特征坍缩。

## 三、实验现象与代数证明

以 4 个全连接节点、初始特征完全同质化（全为 `[2, 7]`）为例：
1. 第 1 层：方差为 0。系统触发相变（乘3 + 索引偏置）。4个节点基准值拉开为 `6, 7, 8, 9`。双墙差值完美锁定为 5。
2. 第 2 层：方差升至 0.25。系统继续触发退火（乘2 + 索引偏置），节点重组为 `6, 7, 6, 7`。
3. 第 3 层：系统再次相变，演化至 `1, 9, 3, 1`。

在传统 GNN 必然发生同质化坍缩的极端测试下，TokamakConv 通过确定性的代数相变维持了节点的表达力，且所有输出永远符合双墙约束（差值=5）。

## 四、代码实现

    def tokamak_conv_forward(H, A, layer_idx, threshold=0.5):
        """
        TokamakConv 单层前向传播（简化模拟）。
        """
        N = len(H)
        C = len(H[0])
        
        # 1. 传统邻居特征聚合
        H_agg = [[0] * C for _ in range(N)]
        for i in range(N):
            degree = sum(A[i]) or 1
            for j in range(N):
                if A[i][j] == 1:
                    for c in range(C):
                        H_agg[i][c] += H[j][c]
            for c in range(C):
                H_agg[i][c] = H_agg[i][c] / degree
        
        # 2. 过平滑监测（方差计算）
        base_vals = [round(H_agg[i][0]) % 10 for i in range(N)]
        mean_val = sum(base_vals) / N
        variance = sum((x - mean_val) ** 2 for x in base_vals) / N
        
        # 3. 确定相变 + 位置偏置
        if variance < threshold:
            k = 3 if layer_idx % 2 != 0 else 2
            for i in range(N):
                base_vals[i] = (base_vals[i] * k + i) % 10 # 节点级位置偏置
                
        # 4. 强制双墙约束
        H_out = []
        for i in range(N):
            v0 = base_vals[i]
            v1 = (v0 + 5) % 10
            H_out.append([v0, v1])
            
        return H_out

## 五、工程价值

1. **防幻觉与抗过平滑统一**：过平滑是模型产生幻觉（对任何输入都输出同一结果）的根源。通过纯整数相变，强制刷新了模型的感受野。
2. **极低功耗**：所有的干预算子（乘、加、取模）都是纯整数操作，极度契合低功耗边缘计算芯片（如 FPGA）。
3. **物理级护栏**：将“差值恒为 5”的拓扑规律注入神经网络，使模型天然具备了守恒律。

## 六、结论

| 验证项 | 结果 |
|---|---|
| 双墙约束 | 强制差值恒为 5，提供绝对残差基准 |
| 过平滑监测 | 基于方差触发确定相变，避免随机性 |
| 位置偏置 | 引入节点索引，完美拉开同质化特征 |
| 工程实现 | 纯整数运算，适合低功耗硬件加速 |
