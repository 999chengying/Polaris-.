# TokamakConv：基于八卦炉拓扑约束的图神经网络图层

## 一、这篇解决什么问题

图神经网络（GNN）在深层堆叠时，面临一个致命的数学宿命：**过平滑（Over-smoothing）**。随着层数加深，消息传递机制会让所有节点的特征无限趋同，最终变成一潭死水，方差为0，丧失辨识能力。
现有的解法多为简单的 Dropout 或残差连接。本文提出 **TokamakConv（托卡马克图卷积层）**，将 Polaris 的“双墙生成数约束”与“巽风退火/逆元相变”引入 GNN，用纯整数模空间（模10）的代数规则，从根本上根治过平滑，并保证特征的拓扑合法性。

## 二、核心架构设计

### 1. 双墙硬约束（保底护栏）
传统 GNN 让通道自由学习，容易在深层传播中失真。
在 TokamakConv 中，我们将隐藏层特征分为两路：
*   通道 0（生数墙 X=1）：保存主特征。
*   通道 1（成数墙 X=5）：**强制等于通道 0 加 5（模10）**。
无论网络多深，这两路特征的差值永远锚定为 5。这相当于给模型加上了一道“物理磁约束”，防止特征在浮点计算中崩坏。

### 2. 相变干预（破局核心）
每一层前向传播后，系统统计通道 0 特征的方差（Variance）。
*   **若方差 < 阈值（过平滑预警）**：
    *   **奇偶相间触发机制**：在奇数层触发【逆元相变（乘3）】，在偶数层触发【巽风退火（乘2）】。
    *   **空间相位偏移**：为了彻底打破全局同质化，算子必须结合图节点的空间拓扑（如节点索引 \(i\)），执行 `val = (val × k + i) mod 10`。
    *   此扰动强制将相同的数字拉开（如全为2的节点，经乘3加偏移后，变为 6,7,8,9），瞬间逆转特征坍缩。

## 三、实验结果与现象分析

以 4 个全连接的节点、初始特征全部为 `[2, 7]` 为例：
1. **第 1 层**：方差为 0。系统自动触发【乘3 + 节点索引偏移】。4个节点的基准值瞬间拉开为 `6, 7, 8, 9`。双墙差值完美锁定为 5。
2. **第 2 层**：邻居聚合后方差升至 0.25。因未过阈值，继续触发【乘2 + 偏移】，节点重组为 `6, 7, 6, 7`。
3. **第 3 层**：系统再次相变，特征演化至 `1, 9, 3, 1`。

**结论**：在传统 GNN 必然发生同质化坍缩的极端测试下，TokamakConv 通过代数相变成功维持了节点的表达力，且所有输出状态永远符合双墙约束（差值=5）。

## 四、AI 工程意义

1. **防幻觉与抗过平滑的统一**：同质化是模型产生幻觉（对任何输入都输出同一结果）的根源。八卦炉的逆元相变通过离散代数手段，强制刷新了模型的感受野。
2. **极具能效的纯整数推理**：干预算子（乘2、乘3、模10）全部是纯整数运算，极度契合低功耗边缘芯片（如 FPGA），比传统的浮点 Attention 矩阵乘法更节能。
3. **物理规律的注入（Physical-Informed AI）**：将“生数墙与成数墙相差 5”的易理拓扑注入神经网络，让模型拥有了天生的守恒律。
