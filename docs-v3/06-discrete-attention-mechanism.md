# Polaris V3-06：幂零注意力投影：摆脱指数运算的纯整数稀疏机制

## 一、本文解决什么问题

现代 Transformer 模型的 Attention 机制严重依赖 Softmax 函数和 \(e^x\) 指数运算，这带来了两大痛点：一是浮点指数运算极其消耗算力，在边缘设备上难以部署；二是当特征维度较高时，长尾效应会导致注意力权重极度稀释（趋近于 0）。
本文基于纯整数模运算，提出一种**“幂零注意力投影机制（Nilpotent Attention Projection）”**。通过模 9 幂零半群的性质，直接对原始匹配分数进行稀疏化硬截断，彻底摒弃了指数与浮点除法，实现了极低功耗的注意力分配。

## 二、核心机制：幂零投影归一化

### 1. 纯整数匹配（Integer QK^T）
摒弃浮点向量点乘，Q 与 K 的匹配分数 \(S_{ij}\) 直接在模 10 空间内进行计算：
\(S_{ij} = (\sum Q_{ik} K_{jk}) \pmod{10}\)

### 2. 幂零半群稀疏化（Nilpotent Normalization）
在模 9 群中，3 是一个幂零元（\(3^2 \equiv 0 \pmod{9}\)）。利用这一代数特性，我们对匹配分数进行 01 截断投影：
- 计算 \(Temp = (S_{ij} \times 3) \pmod{9}\)
- 如果 \(Temp == 0\)（说明该分数落入特定的 3 的倍数集合），则赋予注意力权重 \(A_{ij} = 1\)。
- 否则，\(A_{ij} = 0\)。

通过这一步，原本连续的注意力分数被瞬间转化为极度稀疏的 **0/1 二值矩阵（Binary Masking）**。

## 三、工程价值

1. **硬件级降维打击**：整个 Attention 层的匹配与权重分配，全部是整数加法与取模，彻底剔除了浮点乘法与指数运算，算力消耗呈指数级下降。
2. **绝对稀疏性**：由于幂零性质，非关键节点的注意力权重直接归 0，避免了参数冗余，自带强力的正则化效果。
3. **规避长尾稀释**：不像 Softmax 会出现极小的长尾概率，该机制直接进行硬截断，保留核心特征。

## 四、代码实现

    def nilpotent_attention(Q, K):
        """
        纯整数幂零注意力机制。
        """
        seq_len = len(Q)
        A = [[0] * seq_len for _ in range(seq_len)]
        
        for i in range(seq_len):
            for j in range(seq_len):
                # 1. 纯整数点乘
                score = sum(Q[i][d] * K[j][d] for d in range(len(Q[0]))) % 10
                
                # 2. 模9幂零投影
                if (score * 3) % 9 == 0:
                    A[i][j] = 1 # 激活
                else:
                    A[i][j] = 0 # 屏蔽
                    
        return A
