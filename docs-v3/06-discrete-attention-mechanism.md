# 斩首Softmax：基于双墙通关与幂零坍缩的纯整数注意力（Integer Attention）

## 一、痛点：连续 Softmax 的算力黑洞
\(Softmax(x_i) = \frac{e^{x_i}}{\sum e^{x_j}}\) 存在两个致命缺陷：
1. **指数运算极耗算力**：在边缘设备（如手机、FPGA）上，浮点指数运算是性能杀手。
2. **梯度消失与稀释**：当特征维度很高时，指数项会变得极大或极小，导致注意力矩阵要么全部是0（死寂），要么全集中在一点（模式坍塌）。

## 二、杀招：纯整数拓扑注意力（Integer Attention）
在 Polaris 中，我们摒弃除法与指数，改用**模10代数**直接计算注意力权重。

### 1. 拓扑硬路由（Topological Hard Routing）
对于 Q 和 K，我们不再计算浮点内积，而是计算它们的**九宫距离**或**模10差值**。
设有状态对 \((Q, K)\)，利用生成数对（如8,3）进行通关检测：
*   若通过生成数对能直接借 0/借 5，则分配最高权重（如同在同一个拓扑边）。
*   若无法通关，则通过乘2/乘4（巽风退火）直接将其注意力权重**归零**（幂零半群特性）。

### 2. 幂零坍缩归一化（Nilpotent Normalization）
设 Attention 原始得分为 \(S_{ij} \in \mathbb{Z}_{10}\)。
我们采用模9幂零算子进行归一化：
\[ A_{ij} = \begin{cases} 1, & \text{if } (S_{ij} \times 3) \bmod 9 = 0 \\ 0, & \text{otherwise} \end{cases} \]
这使得注意力矩阵瞬间变成一个**由纯 0 和 1 组成的离散稀疏矩阵**。

## 三、AI 工程价值：硬件级的降维打击
1. **零浮点乘法**：整个 Attention 层的 QK 匹配与权重分配，全部是整数加法与取模运算。
2. **硬件极度友好**：这种“硬路由”注意力可以直接用查表（Look-up Table）和门电路实现，算力消耗只有标准 Transformer 的百分之几。
3. **绝对稀疏性**：由于幂零坍缩，非关键节点的注意力直接归 0，避免了参数冗余，相当于自带了一种强力的正则化。
