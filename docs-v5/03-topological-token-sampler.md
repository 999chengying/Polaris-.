# Polaris V5-03：离散拓扑解码器：纯整数伪随机采样与长程状态生成

## 一、本文解决什么问题

在纯整数自回归生成模型中，如果采用确定性的状态推演，系统极易在达到某个稳态后陷入无限循环（复读机现象）。现代大语言模型通常依赖 Temperature 参数与 Softmax 进行概率采样，但这需要昂贵的浮点指数运算。
本文提出一种**“离散拓扑解码器（Discrete Topology Decoder）”**。通过高维坐标映射与纯整数线性同余发生器（LCG），在不使用任何浮点运算的前提下，彻底打破生成死锁，实现具备长程记忆与语义连贯性的文本序列生成。

## 二、核心算法：高维索引与伪随机扰动

1. **状态空间映射**：将三维拓扑状态 (d1, d2, d3) 转换为一个高维基础索引：Base_Index = 100*d1 + 10*d2 + d3。
2. **纯整数伪随机发生器**：采用线性同余法生成偏置量，计算公式为：
   Seed_new = (Seed * 1103515245 + 12345) % 2147483648
3. **词表映射采样**：计算最终 Token 索引：Token_ID = (Base_Index + Random_Offset) % Vocabulary_Size。

通过引入伪随机偏置，即使系统内部状态达到了绝对稳态（如 5），解码器依然能输出具有多样性的词汇。

## 三、工程实现与代码

    def topological_token_sampler(state, vocab_size, seed=42):
        """
        离散拓扑解码器。
        """
        d1, d2, d3 = state
        
        # 1. 高维基础索引
        base_index = (d1 * 100) + (d2 * 10) + d3
        
        # 2. 纯整数伪随机扰动
        new_seed = (seed * 1103515245 + 12345) % 2147483648
        random_offset = new_seed % vocab_size
        
        # 3. 采样输出
        token_id = (base_index + random_offset) % vocab_size
        return token_id, new_seed
