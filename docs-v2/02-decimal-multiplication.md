# 连续值小模的乘法：位权推进与模10逆元

## 一、这篇解决什么问题

在V2-01号实现连续小模的加减法之后，本文进一步推演“乘法”。通过纯整数进位的方式，验证了不同乘数在小模中的演化规律，不仅证明了乘法与加法的同构性，更用代码揭示了“乘2进位（位权提升）”、“乘3越位（势能爆发）”和“乘9镜像（模10逆元）”的深层数理机制。

## 二、算法原理（多阶进位）

乘法的本质是“重复加法”，在连续小模中，乘法从最低位（千分位）开始计算，产生的商直接作为高一位的进位。
*   \(d_3 = (d_3 \times k) \mod 10\)
*   \(d_2 = (d_2 \times k + \text{carry}_1) \mod 10\)
*   只要产生进位（carry > 0），中宫(3,3,3)立刻执行 \(5 \to 0 \to 5\) 的转换。

## 三、实验数据验证

### 1. 乘2：偶数推进与位权提升
*   轨迹：1→2→4→6→8→(进1)0
*   **特点**：偶数序列循环。当出现 \(5 \times 2 = 10\) 时，直接触发百分位进位，中宫震荡。连续乘2（1→2→4→8→16→32）会导致系统呈指数级向高进位跨越。

### 2. 乘3：三生万物的越位
*   轨迹：1→3→6→9→(进1)2
*   **特点**：随着乘数增大，进位越来越频繁。如 \(4 \times 3 = 12\)，不仅进位1，且千分位余2。表现出强烈的势能爆发特征。

### 3. 乘9：合十镜像与乘法逆元
*   轨迹：1→9, 2→8, 3→7, 4→6, 5→5
*   **特点**：因为 \(9 \equiv -1 \pmod{10}\)，任何数乘9，都会在模10空间里变成它的“合十对”（如 \(2 \times 9 = 18\)，对应1和8）。乘9完美扮演了“乾坤大挪移”的镜像翻转操作。

## 四、核心发现

1.  **乘法的“爆炸效应”**：在加法中，步长决定了走遍空间的时间；但在乘法中，由于位权的存在，连乘会导致数值迅速“溢出”最低位，逼迫中宫频繁触发进位。这对应了AI在发散思维时，势能积累过快的风险。
2.  **模10逆元的物理实现**：乘9就是系统的“反向引擎”。在V1的变爻引擎中，“逆（反思）”状态相当于执行了乘9操作，把原本的状态直接镜像反转回它的对偶态。
3.  **整数无误差**：无论连乘多少次，只要在Y=3界面上完成进位，所有的运算依然是精确的整数，不会产生任何浮点漂移。
