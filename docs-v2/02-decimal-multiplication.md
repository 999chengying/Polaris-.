# Polaris V2-02：连续值小模的乘法：逐位推进与模10逆元

## 一、本文解决什么问题

在确立了连续值小模的加减法基础后，本文进一步定义纯整数域下的乘法运算。现代浮点乘法在深度学习中会造成精度积累误差，而本文通过“逐位乘法与进位”的纯整数机制，不仅证明了乘法与加法在模10状态机下的同构性，还系统性地揭示了不同乘数（如2、3、9）对系统遍历周期和拓扑相变的决定性作用，为纯整数高维矩阵运算奠定基础。

## 二、核心算法：多阶进位乘法

乘法的本质是重复加法。在连续值小模中，乘法运算从最低位（千分位）开始，产生的商直接作为进位累加到高一位，并在任一位溢出时触发全局状态机重置：

1. d3_new = (d3 × k) mod 10，向上位产生进位 carry_1。
2. d2_new = (d2 × k + carry_1) mod 10，向上位产生进位 carry_2。
3. d1_new = (d1 × k + carry_2) mod 10，产生最终进位 carry_3。
4. 只要计算过程中产生有效进位（carry > 0），立刻触发全局状态机：5 → 0 → 5。

## 三、乘数 k 的代数性质与演化规律

### 1. 乘数 k=2（偶数推进与指数溢出）
- 状态轨迹：1 → 2 → 4 → 6 → 8 → (进位) 0。
- 数学特性：呈现偶数序列循环。当千分位数值达到或超过 5 时（例如 5 × 2 = 10），直接向高位进位并触发状态机。连续乘2会导致系统呈指数级向高位跨越，引发快速溢出。

### 2. 乘数 k=3（级联进位与高势能爆发）
- 状态轨迹：1 → 3 → 6 → 9 → (进位) 2。
- 数学特性：随着乘数增大，进位频率显著增高（例如 4 × 3 = 12，不仅高位进1，且千分位余2）。在相空间演化中，乘3会加速系统状态的折叠与重组。

### 3. 乘数 k=9（模10逆元与镜像翻转）
- 状态轨迹：1 → 9，2 → 8，3 → 7，4 → 6，5 → 5。
- 数学特性：在模10群中，9 ≡ -1。任何数乘9，在模10空间内等价于取其加法逆元（x × 9 ≡ -x (mod 10)）。
- 工程意义：乘9在系统中扮演了绝对的“状态翻转”操作，将原本的状态直接镜像映射到其加法对偶态。

## 四、代码实现

    def mul_k(state, k):
        """
        连续值小模乘法。
        返回: (新状态, 总进位次数)
        """
        d1, d2, d3 = state
        total_carries = 0
        
        # 千分位乘法
        raw3 = d3 * k
        carry1 = raw3 // 10
        d3_new = raw3 % 10
        if carry1 > 0: total_carries += carry1
        
        # 百分位乘法
        raw2 = d2 * k + carry1
        carry2 = raw2 // 10
        d2_new = raw2 % 10
        if carry2 > 0: total_carries += carry2
        
        # 十分位乘法
        raw1 = d1 * k + carry2
        carry3 = raw1 // 10
        d1_new = raw1 % 10
        if carry3 > 0: total_carries += carry3
        
        return (d1_new, d2_new, d3_new), total_carries

## 五、结论

| 验证项 | 结果 |
|---|---|
| 乘2进位 | 触发状态机，呈现指数级高位溢出 |
| 乘3进位 | 进位频繁，引发状态的折叠与重组 |
| 乘9翻转 | 完美等价于取模10加法逆元（x × 9 ≡ -x） |
| 状态机枢纽 | 所有有效进位均严格触发 5 → 0 → 5 状态重置 |
| 整数无误差 | 无论连乘多少次，完全保持纯整数运算，无浮点漂移 |
