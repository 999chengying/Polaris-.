# Polaris V2-01：连续值小模的加法与减法：状态机进位与模10封闭性

## 一、本文解决什么问题

现代大语言模型（Transformer）极度依赖高维浮点矩阵运算，导致严重的算力消耗与难以消除的浮点精度漂移。
本文定义“连续值赋值小模”的加法与减法基础规则，证明所有高精度算术都可以挂载在离散的模10状态机和级联进位机制上，从而彻底摒弃浮点运算，为构建纯整数高精度计算引擎奠定底层基石。

## 二、状态表示与结构定义

1. **小模状态表示**：
   使用三元组 S = (d1, d2, d3) 表示一个精度到千分位的实数的小数部分。
   * d1：十分位，取值 0 ≤ d1 ≤ 9。
   * d2：百分位，取值 0 ≤ d2 ≤ 9。
   * d3：千分位，取值 0 ≤ d3 ≤ 9。

2. **状态机触发器（State Machine Trigger）**：
   在模10运算域中，设定 5 为系统基准稳态。当任一位发生跨模数的溢出或借位时，触发全局状态机切换：5 → 0 → 5。在计算机工程中，这等价于一种带复位校验的超前进位机制，确保系统状态的全局一致性。

## 三、核心算法与代数性质

### 1. 加法与进位级联
当执行 d3 + 1 时，若 d3 = 9，则 d3 归零，向 d2 进 1，并触发状态机。若 d2 同样溢出，则继续向 d1 级联。

### 2. 减法与边界翻转（Void Inversion）
当执行 d3 - 1 时，若 d3 = 0，则向高位借位，d3 变为 9。
临界性质（边界翻转）：当系统状态为绝对零点 (0,0,0) 并执行减 1 时，由于无更高位可借，系统发生模10空间的拓扑翻转，直接坍缩为全 9 状态 (9,9,9)。
* 数学意义：由于 -1 ≡ 9 (mod 10)，该性质保证了系统在闭区间 [0, 9] 内的加减运算具备完整的封闭性和可逆性，彻底杜绝了计算越界死锁。

### 3. 步长周期定理
对于加法步长 k（1 ≤ k ≤ 9），系统的遍历周期完全取决于 k 与 10 的最大公约数 gcd(k, 10)：
* 若 gcd(k, 10) = 1（如 k=1,3,7,9），系统满射遍历 10 个状态（全遍历）。
* 若 gcd(k, 10) = 2（如 k=2,4,6,8），系统收敛至 5 个偶数或奇数状态（半遍历）。
* 若 k=5，系统在 {0, 5} 之间发生二态驻波震荡。

## 四、代码实现

    def add_one(state):
        d1, d2, d3 = state
        if d3 < 9:
            return (d1, d2, d3 + 1)
        d3 = 0
        if d2 < 9:
            return (d1, d2 + 1, d3)
        d2 = 0
        if d1 < 9:
            return (d1 + 1, d2, d3)
        return (0, d2, d3)

    def sub_one(state):
        d1, d2, d3 = state
        if d3 > 0:
            return (d1, d2, d3 - 1)
        d3 = 9
        if d2 > 0:
            return (d1, d2 - 1, d3)
        d2 = 9
        if d1 > 0:
            return (d1 - 1, d2, d3)
        return (9, 9, 9) # 边界翻转
