# 连续值小模的加减法：进位、借位与中宫齿轮

## 一、这篇解决什么问题

在V1中，我们设计了“连续值赋值小模”（通过X=1,3,5的截面嵌套表示小数）。V2的第一步，是让这个静态模型真正“算”起来。本文定义了小模的**加法（进位）**与**减法（借位）**法则，证明了所有数学运算都严格挂载在 Y=3 界面和中宫5的瞬间转换上。这为彻底摒弃浮点运算、实现纯整数高精度计算奠定了基石。

## 二、数据结构与核心枢纽

*   **状态表示**：三元组 `(d1, d2, d3)`，分别代表十分位、百分位、千分位的值（0~9，0代表无活跃宫）。
*   **中宫齿轮**：中宫 `(3,3,3)=5`。每当发生跨越10的进位或借位时，中宫瞬间执行 `5→0→5` 的相变，充当运算的时空阀门。
*   **关键节点**：`(5,3,5)=9`，`(3,3,1)=9`，`(1,3,1)=1`，`(3,3,5)=1`，全部锁定在 Y=3 截面上。

## 三、加法：进位机制

### 1. 加1法规则
*   正常加1：最低位 `d3 += 1`。
*   进位（d3=9时）：`d3` 清零，中宫 `5→0→5`，高一位 `d2` 加1。
*   级联：若高位同样为9，继续向更高位进位。

### 2. 加k法规律（步长k=1~9）
实验表明，步长 \(k\) 与模10的最大公约数（gcd）决定了系统的遍历周期：
*   **全遍历（k=1,3,7,9）**：gcd=1，周期为10，遍历0~9全部余数。（纯阳演化，生生不息）
*   **半遍历（k=2,4,6,8）**：gcd=2，周期为5，仅遍历特定同余类。（阴阳分判，路径收敛）
*   **驻波（k=5）**：gcd=5，周期为2，每次加5都在0和5之间震荡，疯狂触发中宫转换。

## 四、减法：借位与虚空翻转

### 1. 减1法规则
*   正常减1：`d3 > 0` 时，`d3 -= 1`。
*   借位（d3=0时）：`d3` 变9，中宫 `5→0→5`，高一位 `d2` 减1。
*   级联：若高位为0，继续向更高位借位。

### 2. 虚空翻转（绝对零点的突破）
当从 `(0,0,0)` 减1时：
*   千分位借位，百分位借位，中宫连跳两次。
*   十分位借无可借，发生**“虚空翻转”**，从0跌至9。
*   最终结果：`(9, 9, 9)`。
*   **易理意义**：这正是《道德经》中“天下万物生于有，有生于无”的数理显化。

## 五、加减互逆的完美闭环

加减法在连续小模中形成了完美的莫比乌斯环：
*   `(0,0,9) + 1 = (0,1,0)` （触发进位）
*   `(0,1,0) - 1 = (0,0,9)` （触发借位）
进位与借位，均由中宫(3,3,3)的 `5→0→5` 瞬间转换驱动，证明了 Y=3 界面是系统演化的绝对中枢。

## 六、核心代码（Python）

```python
def add_one(state):
    d1, d2, d3 = state
    if d3 < 9:
        d3 += 1
    else:
        d3 = 0
        # ⚡ 中宫5->0->5
        if d2 < 9:
            d2 += 1
        else:
            d2 = 0
            # ⚡ 中宫5->0->5
            if d1 < 9:
                d1 += 1
            else:
                d1 = 0
                # 溢出重置
    return (d1, d2, d3)

def sub_one(state):
    d1, d2, d3 = state
    if d3 > 0:
        d3 -= 1
    else:
        d3 = 9
        # ⚡ 中宫5->0->5
        if d2 > 0:
            d2 -= 1
        else:
            d2 = 9
            # ⚡ 中宫5->0->5
            if d1 > 0:
                d1 -= 1
            else:
                d1 = 9
                # 虚空翻转
    return (d1, d2, d3)
```
