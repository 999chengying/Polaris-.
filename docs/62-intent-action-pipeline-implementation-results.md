# 意图到执行管道：Python模块化实现与验证

## 一、这篇解决什么问题

在56号伪代码的基础上，给出完整可运行的Python模块实现，验证与55/56号实验结果的一致性，并给出API说明。

适合读者：对管道实现、模块化、可运行代码感兴趣的读者。

前提：27宫立方体，新旧赋值，中宫为5。

## 二、模块结构

    文件：src/intent_action_pipeline.py

    函数：
        build_table(assign)                    构建27宫值表
        mod9(x)                                模9归9
        dist(p, q)                             欧氏距离
        neighbors(pos)                         邻域生成器
        level_of(V, p)                         级别判定
        radius_of(dist_to_center)              半径规则
        scan(V, pos, R, visited)               探测
        decide_T(mode, fixed_T, since, dist_c, last_lv, cur_max)  决策
        move(V, pos, target_value, prev_dir)   执行
        run_pipeline(V, start, k, steps, mode, fixed_T)  主循环

## 三、各函数说明

### build_table

    输入：assign（27宫赋值字典）
    输出：V（坐标到值的字典）
    复杂度：O(27)

### level_of

    输入：V，位置p
    输出：1=Z轴，2=顶点，3=潜伏，0=非4/6
    规则：
        若V[p]不在{4,6}：返回0
        若x==3且y==3：返回1
        若x,y,z均在{1,5}：返回2
        否则：返回3

### radius_of

    输入：距中宫距离
    输出：探测半径
    规则：
        ≤2：2
        ≤3.5：2.828
        否则：3.464

### scan

    输入：V，当前位置，半径R，已访问集合
    输出：(最高级别, 对应位置)
    复杂度：O(27)

### decide_T

    输入：模式，固定阈值，距上次发现步数，距中宫距离，上次级别，当前最高级别
    输出：阈值T
    规则（动态v2）：
        T = 2
        since≥3：T+1
        since≥6：T+1
        dist≥3.5：T+1
        last_lv==3：T-1
        last_lv==1：T+1
        clamp(T, 1, 3)
        若cur_max>0且cur_max<T：T=cur_max

### move

    输入：V，当前位置，目标值，上一步方向
    输出：(下一位置, 新方向)
    评分规则：(-方向惯性, 距离, 坐标)，取最小
    复杂度：O(27)

### run_pipeline

    输入：V，起点，加数k，步数，模式，固定阈值
    输出：{found, avg_level, stuck, log, final_pos}
    复杂度：O(27 × steps)

## 七、核心发现

所有测试结果与55/56号完全一致，包括发现次数、平均级别、卡死状态。

11个函数，职责分明。主循环run_pipeline封装完整流程，返回结果字典。

### 发现三：复杂度符合预期

单步O(27)，总O(27×steps)。实测30步运行时间在手机端小于1秒。
