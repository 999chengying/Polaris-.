# 新27宫赋值：结构、性质与AI架构启示

## 一、背景

在九宫八卦立方体的27宫离散空间中，对18个潜伏单元重新赋值。

新赋值遵循一个原则：

潜伏单元的值 = 相邻活跃单元或面中心单元的模10差值。

由此得到一个五行俱全、四对合十完全显化的结构。

```

z=3 中层：

```

z=5 上层：

## 三、与旧赋值的核心差异

| 维度 | 旧赋值 | 新赋值 |
|---|---|---|
| 值为5的位置 | 7处（中宫+6面心） | 3处（x轴） |
| 潜伏单元数字集合 | 缺2,3,7,8 | 1-9全出现 |
| 生成数对 | 仅1-6、4-9 | 四对俱全 |
| z轴 | 6-5-4 | 2-5-8 |
| 上层链 | 147 | 369 |
| 下层链 | 369 | 147 |
| 五行分布 | 金水偏 | 五行俱全 |

最根本的改动：z轴面中心值从6、4改为2、8。

## 四、中轴显化：258通道

z轴从6-5-4改为2-5-8后：

2 → 5 → 8

这正是258通道，在乘法规则中承担跨通道交换功能，是三条通道中唯一穿过中心的一条。

| 层 | 通道 | 角色 |
|---|---|---|
| 下层 | 147 | 自转 |
| 中轴 | 258 | 跨通道交换 |
| 上层 | 369 | 收敛归核 |

三条通道各占一层，互不混杂。

## 五、潜伏单元的分组结构

### 1. 棱中点承载147与369

147的6个棱中点，分成两组等边三角形，边长2√2，共用顶点1。

369的6个棱中点，分成两组等边三角形，边长2√2，共用顶点9。

### 2. 两组公共顶点体对角对称

1与9关于中宫体对角对称，和10，合十。

余数3与7也体对角对称，和10，合十。

### 3. 四对合十全部显化

| 合十对 | 位置 |
|---|---|
| 1-9 | 前后面中心及棱中点 |
| 2-8 | 上下面中心 |
| 3-7 | 棱中点 |
| 4-6 | 棱中点 |

四对合十全部由潜伏单元承担，且都关于中宫对称。

## 六、三条轴共面

x=3平面上有三条轴：

| 轴 | 序列 | 方向 |
|---|---|---|
| 159 | 1-5-9 | (0,1,0) |
| 258 | 2-5-8 | (0,0,1) |
| 357 | 3-5-7 | (0,1,1) |

三条轴共面于x=3，汇聚中宫5。

第四对合十4-6不在该平面上，斜穿中宫，作为出入口。

三对合十共面，一轴斜穿。

## 七、线性规律

帝5顺行多圈后逆行归中，步数与距离严格成正比：

步数 = 0.5 × 距离

对比旧赋值的0.48，新赋值的0.50更精确。

## 八、AI架构启示

### 1. 结构对应

| 九宫结构 | AI架构 |
|---|---|
| 27状态单元 | 27个计算单元 |
| 9活跃单元 | 常驻激活单元 |
| 18潜伏单元 | 备用计算单元 |
| 中宫5 | 中心调度节点 |
| 合十对 | 预置连接通道 |
| 生成对 | 预置生成路由 |
| 顺行 | 前向执行 |
| 逆行 | 目标对齐 |

### 2. 稀疏激活

传统AI每一层遍历全部参数。

本架构中，常驻激活单元仅9个，其余18个按需激活。

计算量对比：

- 传统：每步遍历全部参数；
- 本架构：每步仅遍历活跃单元。

### 3. 预置路由

四对合十和四对生成数构成预置连接通道，无需搜索。

- 合十对：对称通道，和10；
- 生成对：生成通道，差5。

预置路由省去注意力搜索开销。

### 4. 中心调度

中宫5作为唯一调度节点：

- 接收各单元状态；
- 判断全局收敛；
- 发出归中信号。

一次决策，全局执行。

### 5. 容错机制

活跃单元失效时，潜伏单元可转为活跃。

单元转换保持总数不变。

### 6. 与现有架构对比

| 维度 | 传统Transformer | 本架构 |
|---|---|---|
| 激活 | 全部 | 按需 |
| 路由 | 学习得到 | 预置 |
| 调度 | 分布式 | 中心化 |
| 通信 | 全连接 | 预置通道 |
| 容错 | 冗余备份 | 单元替补 |

本架构与混合专家模型接近，但增加了预置路由和中心调度。

## 九、待验证问题
