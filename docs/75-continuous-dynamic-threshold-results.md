# 连续球面动态阈值v2推广

## 一、这篇解决什么问题

在连续球面上采样，验证4/6覆盖率和动态阈值v2的推广可行性。

前提：27宫旧赋值，球心(3,3,3)，半径2√3。

## 二、实验结果

### 球面20点采样

| 值 | 次数 |
|---|---:|
| 1 | 5 |
| 5 | 4 |
| 4 | 4 |
| 6 | 3 |
| 2,3,7,9 | 各1 |

4/6共7次，占35%。

### 采样点到最近4/6的距离

| 距离 | 级别 |
|---:|---|
| 1.68 | 1 |
| 2.05 | 1 |
| 2.30 | 2 |
| 2.29 | 3 |
| 1.72 | 2 |

## 三、核心结论

1. 连续球面上4/6覆盖35%，充分。
2. 采样点到最近4/6距离1.68-2.3，级别1-3都有。
3. 动态阈值v2在连续球面上有足够候选，可推广。

本文只做结构形式化与离散动力学分析。

## 五、口诀
