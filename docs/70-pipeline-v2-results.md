# 意图到执行管道v2：最优配置落地与验证

## 一、这篇解决什么问题

在67/68号确认r=4 d=1 + 固定T=3为最优配置后，把62号的Python模块更新为最优配置，重跑全场景验证。

适合读者：对管道实现、配置优化、全场景验证感兴趣的读者。

前提：27宫立方体，新旧赋值，中宫为5。

## 二、配置变更

| 项 | 62号模块 | 70号模块 |
|---|---|---|
| neighbors | `(-2,0,2)` | `range(-4,5,2)` |
| 前瞻深度 | 2 | 1 |
| 默认阈值 | 动态v2 | 固定T=3 |
| 动态v2 | 默认 | 保留为可选 |

## 三、模块结构

    文件：src/intent_action_pipeline.py（v2）

    函数：
        build_table(assign, offset=0)          构建27宫值表
        mod9(x)                                模9归9
        dist(p, q)                             欧氏距离
        neighbors(pos, r)                      邻域生成器，r=2/4/6
        level_of(V, p)                         级别判定
        radius_of(d)                           探测半径
        scan(V, pos, R, visited)               探测
        find_raw(V, pos, nv, r)                原始候选
        find_bridge(V, pos, nv, r)             桥接候选
        lookahead_ok(V, pos, nxt, k, depth, r) 前瞻检查
        pick(cand, pos, prev)                  选择
        decide_T(mode, fixed_T, since, d, last, cm)  决策
        run_pipeline(V, start, k, steps, r, depth, mode, fixed_T, sphere)  主循环

    默认配置：
        DEFAULT_R = 4
        DEFAULT_DEPTH = 1
        DEFAULT_MODE = "fixed"
        DEFAULT_T = 3
