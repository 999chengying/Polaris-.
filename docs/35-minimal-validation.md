# 最小验证：离散序列预测

## 一、这篇解决什么问题

验证固定拓扑法在规则明确的任务上，是否比可训练模型更省。

适合读者：对稀疏激活、预置路由、省算力感兴趣的读者。

前提：任务规则已知，序列按固定链循环。

## 二、任务设计

输入：前k个数字。

输出：下一个数字。

规则：按加3链循环。

- 1→4→7→1→4→7...
- 2→5→8→2→5→8...
- 3→6→9→3→6→9...

## 三、对比方法

| 方法 | 参数量 | 训练 | 推理 |
|---|---:|---|---|
| 固定拓扑 | 0 | 零训练 | 查链 |
| 统计模型 | 81 | 需统计 | 查表 |
| 小型RNN | 208 | 需训练 | 逐步推理 |

## 四、实验结果

| 方法 | 参数量 | 训练样本 | 推理操作 | 正确率 |
|---|---:|---:|---:|---:|
| 固定拓扑 | 0 | 3 | 171 | 100% |
| 统计模型 | 81 | 3 | 513 | 100% |
| 小型RNN | 208 | 3 | 11856 | 22.8% |

## 五、结论

规则明确时，固定拓扑零参数、零训练、100%正确。

统计模型也能100%，但参数多、操作多。

小型RNN正确率低，是因为训练样本太少，未充分训练。

本实验不证明RNN不行，只证明在规则明确且样本稀缺时，固定拓扑更省。

## 六、适用边界

固定拓扑优势成立的条件：

1. 规则明确且固定；
2. 任务属于路径导航或序列预测；
3. 对可解释性有要求；
4. 训练数据稀缺。

固定拓扑不适用场景：

1. 规则模糊，需从数据学习；
2. 任务涉及感知、语言；
3. 规则频繁变化。

## 七、与AI架构的对应

固定拓扑相当于预置路由。

统计模型相当于查表。

小型RNN相当于可训练网络。

三者可互补：

- 固定拓扑处理规则明确的部分；
- 可训练网络处理规则模糊的部分；
- 中心节点做仲裁调度。

## 八、边界声明

本实验只对比一种规则：加3。

结论不能直接外推到所有任务。

可定义、可推导、可检验；有用则留，无用则弃。

## 九、口诀

规则明确零训练，固定拓扑即百分。
统计虽好参数多，RNN需训样本足。
三者互补非替代，混合架构是正途。
边界条件要记清，实事求是方为真。
