# 跨域通信：从九宫空间跨单元连接看通信架构

## 一、实验事实

在27宫新赋值下，统计无限周期空间中活跃单元之间的连接。

跨单元连接（距离2）：

| 差值 | 次数 | 占比 |
|---:|---:|---:|
| 1 | 8 | 33.3% |
| 2 | 8 | 33.3% |
| 5 | 8 | 33.3% |
| 其他 | 0 | 0% |

单元内连接：

| 距离 | 差值分布 |
|---|---|
| 4（面） | 1、2、5 |
| 4√2（面对角） | 1、3、4、6、7 |
| 4√3（体对角） | 2、4、6、8 |

核心事实：

跨单元连接只用差值1、2、5，均匀三分。

单元内连接混杂，差值1到8都有。

跨单元强连接（差5）数量是单元内的2倍。

## 二、翻译成通信原则

### 原则一：跨域接口标准化

跨单元只用差值1、2、5，相当于三种标准接口。

不是任意两节点都能直连，只有三种标准连接类型。

通信含义：跨域通信要有标准接口，不能随意定制。

### 原则二：域内可以复杂，域间必须简单

单元内连接混杂，跨单元连接纯净。

- 单元内：节点之间的连接可以复杂；
- 跨单元：只走标准通道。

通信含义：域内可以私有协议，跨域必须走标准网关。

### 原则三：跨域连接是主力

跨单元强连接（差5）数量是单元内的2倍。

跨单元连接（每个面4对，6个面共24对）远多于单元内（4对）。

通信含义：系统的主要通信量在域间，不在域内。

## 三、与动态目标模型结合

之前动态目标模型结论：

查询频率要与目标变化频率匹配。

现在加上跨域连接结论：

跨域通信只用三种标准接口。

两者结合：

标准接口 + 按需频率 = 高效跨域通信

## 四、与现有通信架构对照

| 通信架构 | 对应 |
|---|---|
| 域内路由 | 单元内连接，复杂 |
| 域间路由 | 跨单元连接，标准 |
| BGP | 跨域标准协议 |
| OSPF | 域内协议 |
| 数据中心东西向流量 | 跨单元为主 |
| 南北向流量 | 单元内部 |

跨域流量是主力，域内流量是辅助。

## 五、落地启示

| 层面 | 做法 |
|---|---|
| 接口 | 跨域只用三种标准协议 |
| 频率 | 按目标变化频率调整 |
| 拓扑 | 跨域连接为主，域内为辅 |
| 边界 | 域内私有，跨域标准 |
| 调度 | 中心节点统一协调 |

## 六、边界声明

本文是结构类比，不是实际通信协议设计。

实际通信还需考虑：

- 延迟；
- 带宽；
- 拥塞；
- 安全；
- 故障恢复。

模型基于27宫离散空间，不能直接外推到真实网络。

可定义、可推导、可检验；有用则留，无用则弃。
