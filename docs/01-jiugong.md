# Polaris 基础架构：三维正交拓扑编码、空间映射与子图剪枝

## 一、本文解决什么问题

在构建纯整数心智引擎时，如何将离散的状态（如 1~9 的整数）映射到具有空间结构的三维网络中，并剔除无效的图连接，是建立特征关联与路由的基础。本文基于传统东方九宫格架构的启发，提出一种**“三维正交拓扑编码规范”**及**“几何子图剪枝算法”**。该规范将离散数字映射至立方体的顶点与中心，并通过节点间的空间距离剔除共面冗余，为后续的图神经网络（GNN）与局部特征聚合提供底层的几何数据结构。

## 二、三维坐标系与状态映射

### 1. 空间坐标定义
我们定义一个三维笛卡尔空间，其取值范围为 \(X, Y, Z \in \{1, 3, 5\}\)，构成一个边长为 2 的 \(3 \times 3 \times 3\) 网格（27宫格）。
- 空间重心坐标为 \((3, 3, 3)\)。
- 所有小立方体的重心坐标由 \((i, j, k)\) 唯一确定。

### 2. 顶点状态映射（八面体映射）
我们将 8 个基础整数状态映射至该网格的 8 个顶点，作为系统的“活跃宫/主特征”。
- 状态 9 映射至 \((1, 1, 1)\)
- 状态 4 映射至 \((5, 1, 1)\)
- 状态 3 映射至 \((5, 5, 1)\)
- 状态 8 映射至 \((1, 5, 1)\)
- 状态 7 映射至 \((1, 1, 5)\)
- 状态 2 映射至 \((5, 1, 5)\)
- 状态 6 映射至 \((1, 5, 5)\)
- 状态 1 映射至 \((5, 5, 5)\)
- 状态 5 位于系统重心 \((3, 3, 3)\)，作为全局状态锚点（基准稳态）。

## 三、几何子图提取与拓扑剪枝（五形规则）

在三维空间中，任意 4 个节点可以构成一个子图。为了防止图网络在训练或路由时发生“空间坍缩（即所有节点都挤在同一个二维平面上）”，我们引入**“基于空间距离的剪枝规则”**。

通过计算子图内 6 条边（即 4 个节点两两组合）的距离平方，系统对子图的几何形状进行分类，并进行剪枝：

1. **剔除共面节点（空形/无效子图）**：
   如果 4 个节点全部位于一个 3x3 的截面上（如位于 X=1 或 Y=3 的平面），则这 4 个节点的体积为 0。系统判定其构不成三维拓扑结构，直接剪枝剔除。
   - 数学判定：计算 4 个点的混合积，若为 0，则共面剔除。

2. **保留有效几何体（正四面体 / 变体）**：
   若 4 个节点不共面，则构成三维有效子图（如正四面体，其节点间距离平方组合为 {1,1,1,2,2,2}；或其他畸变四面体）。只有这些具备三维体积的节点组合，才能参与后续的特征计算。

3. **中宫剔除（锚点保护）**：
   中心节点 5 作为全局基准态，在构建基础子图时禁止与普通节点同格参与局部的四面体计算，以防止基准态被过度同化。

## 四、代码实现

    COORDS = {
        9: (1, 1, 1), 4: (5, 1, 1), 3: (5, 5, 1), 8: (1, 5, 1),
        7: (1, 1, 5), 2: (5, 1, 5), 6: (1, 5, 5), 1: (5, 5, 5),
        5: (3, 3, 3)
    }

    def get_distance_sq(node_a, node_b):
        """计算两个节点的欧氏距离平方"""
        coord_a = COORDS[node_a]
        coord_b = COORDS[node_b]
        return sum((coord_a[i] - coord_b[i]) ** 2 for i in range(3))

    def is_coplanar(nodes):
        """判断4个节点是否共面（体积为0）"""
        import numpy as np
        p0, p1, p2, p3 = [COORDS[n] for n in nodes]
        v1 = [p1[i] - p0[i] for i in range(3)]
        v2 = [p2[i] - p0[i] for i in range(3)]
        v3 = [p3[i] - p0[i] for i in range(3)]
        # 混合积为0则共面
        return np.dot(v1, np.cross(v2, v3)) == 0

    def extract_geometric_subgraph(nodes):
        """
        对输入的4个节点进行几何判定与剪枝。
        """
        if len(set(nodes)) != 4 or 5 in nodes:
            return "无效输入或包含中宫锚点"
            
        if is_coplanar(nodes):
            return "空形：共面节点被剪枝剔除"
            
        # 计算距离分布模式
        ds = sorted([get_distance_sq(a, b) for i, a in enumerate(nodes) for b in nodes[i+1:]])
        return f"保留子图，距离特征分布: {ds}"

    # 测试用例
    print(extract_geometric_subgraph([9, 4, 3, 8])) # 共面（Z=1截面），被剔除
    print(extract_geometric_subgraph([9, 4, 7, 2])) # 非共面，保留

## 五、结论

| 验证项 | 结果 |
|---|---|
| 空间完备性 | 1~9 状态被无歧义映射至 3D 网格 |
| 几何剪枝 | 共面节点（空形）被自动识别并剔除 |
| 子图提取 | 通过距离平方分布，精准识别有效三维拓扑 |
