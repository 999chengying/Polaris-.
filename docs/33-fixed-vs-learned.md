# 固定拓扑 vs 可训练网络：规则已知与数据不全时的对比

## 一、实验设计

任务：一步状态转移。

规则：y = mod9(x + 3)

方法一：固定拓扑。硬编码加3规则，零训练，直接计算。

方法二：可训练网络。单隐层MLP，完整反向传播，训练充分。

两个场景：

1. 训练集完整：9条数据，覆盖起点1到9。
2. 训练集不完整：5条数据，只含起点1到5；测试起点6到9。

评价：递归预测k步后的结果，k从1到10。

## 二、对比一：训练集完整

训练数据覆盖所有起点。

| 方法 | 正确率 |
|---|---:|
| 固定拓扑 | 100% |
| MLP | 100% |

结论：

规则可学时，充分训练的MLP也能达到100%。

固定拓扑的优势是零训练，MLP的优势是可从数据学习。

## 三、对比二：训练集不完整

训练数据只含起点1到5，测试起点6到9。

| 方法 | 正确率 |
|---|---:|
| 固定拓扑 | 100% |
| MLP | 5% |

结论：

规则已知但数据不全时，固定拓扑靠规则泛化，仍达100%。

MLP靠数据泛化，未见起点全部失败。

## 四、本质区别

| 维度 | 固定拓扑 | 可训练网络 |
|---|---|---|
| 知识来源 | 规则 | 数据 |
| 训练需求 | 零 | 大量 |
| 泛化方式 | 规则外推 | 数据插值 |
| 未见输入 | 仍能处理 | 可能失败 |
| 规则变化 | 重新编码 | 微调 |
| 可解释性 | 高 | 低 |

固定拓扑是规则驱动。

可训练网络是数据驱动。

## 五、适用场景

| 场景 | 推荐方法 |
|---|---|
| 规则明确、数据稀缺 | 固定拓扑 |
| 规则模糊、数据充足 | 可训练网络 |
| 规则明确、数据充足 | 两者皆可 |
| 规则变化频繁 | 可训练网络 |
| 实时响应、零训练 | 固定拓扑 |

## 六、互补而非替代

固定拓扑处理规则明确的部分。

可训练网络处理规则模糊的部分。

两者结合：

固定拓扑 + 可训练网络 = 混合架构

中心节点可做仲裁调度。

## 七、边界声明

本实验只对比一种规则：加3。

结论不能直接外推到所有任务。

规则更复杂时，固定拓扑的编码成本上升。

任务涉及感知、语言时，可训练网络更有优势。

真实场景往往是两者混合。

可定义、可推导、可检验；有用则留，无用则弃。

## 八、口诀

规则明确零训练，固定拓扑即百分。

数据齐全两皆可，规则模糊网络能。

互补而非替代用，混合架构是正途。

边界条件要记清，实事求是方为真。
