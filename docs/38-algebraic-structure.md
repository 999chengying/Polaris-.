# 三条链的代数结构

## 一、这篇解决什么问题

验证147、258、369三条链在模9运算下的代数结构。

适合读者：对模运算、群结构、数字链感兴趣的读者。

前提：纯代数验证，不涉及空间，不涉及连续。

## 二、加法闭包

| 加法 | 结果 |
|---|---|
| 147 + 147 | 258 |
| 147 + 258 | 369 |
| 147 + 369 | 147 |
| 258 + 258 | 147 |
| 258 + 369 | 258 |
| 369 + 369 | 369 |

三条链在模9加法下构成3阶循环群。

369是单位元。

147是3阶元。

258等于147加147。

## 三、乘法闭包

| 乘法 | 结果 |
|---|---|
| 147 × 任何 | 任何 |
| 258 × 258 | 147 |
| 369 × 任何 | 369 |

147是乘法单位元。

258是二阶元。

369是乘法零元。

## 四、加3封闭

每个数加3，留在本链。

加3是三条链各自的循环生成元。

## 五、前面现象的统一解释

| 现象 | 代数解释 |
|---|---|
| 加3总是封闭 | 三条链是Z/3的三个元素 |
| 乘369总是归核 | 369是乘法零元 |
| 147与258互为逆元 | 加法中互逆 |
| 369是稳定核 | 加法单位元加乘法零元 |

三条链不是随意划分，是模9运算的自然分解。
