# Polaris 理论对账：纯整数拓扑的有限代数结构分析

## 一、本文解决什么问题

在构建纯整数心智引擎时，系统为何能够做到“零浮点漂移”、“极速收敛”以及“无损回滚”？这并非工程上的偶然，而是由底层所采用的离散数学空间（模运算）的**有限代数结构（Finite Algebraic Structure）**决定的。
本文系统性地分析 Polaris 引擎中所采用的模10加法群、模10乘法半群、模9幂零半群与模24循环群，揭示这些代数结构如何为状态演化、防死锁路由与极值相变提供坚不可摧的数学保障。

## 二、核心代数结构解析

### 1. 模10加法群（\(\mathbb{Z}_{10}, +\)）与拓扑折叠
- **结构特性**：构成一个包含 10 个元素的有限循环群。其单位元为 0，元素 \(x\) 的逆元为 \(10 - x\)。
- **工程应用**：保证状态机进位与借位的完全可逆。例如，\(+1\) 的逆元是 \(-1 \equiv 9 \pmod{10}\)。在状态机中，溢出值必定在有限步内折叠回安全域。

### 2. 模10乘法半群（\(\mathbb{Z}_{10}, \times\)）与单位群 \(U(10)\)
- **结构特性**：在模10乘法下，并非所有元素都可逆。只有与 10 互质的元素 \(\{1, 3, 7, 9\}\) 构成了乘法群 \(U(10)\)。
- **工程应用**：这组成了系统的“状态旋转与镜像算子”。
  - 乘 9 是自逆元（\(-1\)），实现全盘反转。
  - 乘 3 与乘 7 互为逆元（\(3 \times 7 \equiv 1\)），构成可无损回滚的双向路由。

### 3. 模9幂零半群（\(\mathbb{Z}_{9}, \times\)）与注意力坍缩
- **结构特性**：对于 3 的倍数，存在幂零性，即 \(3^2 \equiv 0 \pmod{9}\)。
- **工程应用**：这是纯整数注意力机制的核心。通过对匹配分数乘以 3 再模 9，系统能极速剔除无效的噪声连接（将其归 0 或 9），实现极端的稀疏化路由（Winner-Takes-All）。

### 4. 模24循环群（\(\mathbb{Z}_{24}, +\)）与采样路由
- **结构特性**：包含 24 个元素的循环群，具备丰富的子群结构（因数有 1,2,3,4,6,8,12,24）。
- **工程应用**：用于时间序列的均匀遍历。步长 \(K\) 与 24 的最大公约数（GCD）直接决定了采样周期。如 \(K=5\) 产生完美的遍历回文；\(K=6\) 产生 GQA（分组查询注意力）所需的多子环。

## 三、代码验证：代数结构性质测试

    import math

    def verify_algebraic_structures():
        print("=== 1. 模10单位群逆元验证 ===")
        for x in [1, 3, 7, 9]:
            # 寻找逆元
            inv = pow(x, -1, 10)
            print(f"  元素 {x} 的逆元是 {inv}，验证: {x} * {inv} % 10 = {(x * inv) % 10}")

        print("\n=== 2. 模9幂零性验证 ===")
        for x in [3, 6, 9]:
            result = (x * 3) % 9
            print(f"  元素 {x} 乘 3 模 9 结果: {result} (是否归零: {result == 0 or result == 9})")

        print("\n=== 3. 模24循环群步长周期验证 ===")
        for K in [1, 5, 6, 12]:
            g = math.gcd(24, K)
            segments = 24 // g
            print(f"  步长 K={K} | 最大公约数: {g} | 遍历段数: {segments}")

    if __name__ == "__main__":
        verify_algebraic_structures()

## 四、结论

| 代数结构 | 数学表示 | 核心性质 | 工程对应 |
|---|---|---|---|
| 加法群 | \((\mathbb{Z}_{10}, +)\) | 逆元 \(x + (10-x) \equiv 0\) | 状态机的进位与无损回退 |
| 乘法群 | \(U(10) = \{1,3,7,9\}\) | 互相可逆，\(3 \times 7 \equiv 1\) | 空间旋转与频率切换 |
| 幂零半群 | \((\mathbb{Z}_{9}, \times)\) | \(3^2 \equiv 0 \pmod{9}\) | 纯整数注意力的稀疏化坍缩 |
| 循环群 | \((\mathbb{Z}_{24}, +)\) | 由 \(K\) 与 24 的 GCD 决定周期 | 序列采样的均匀遍历与分组 |
