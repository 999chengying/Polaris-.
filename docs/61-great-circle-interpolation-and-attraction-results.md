# 大圆插值与双球体吸引力：实验结果

## 一、这篇解决什么问题

在59号的基础上，给出大圆插值算法（slerp），并重新分析双球体吸引力。修正59号"跨球锁死"的结论。

适合读者：对球面插值、双球体导航、吸引力机制感兴趣的读者。

前提：27宫立方体，新旧赋值，球心(3,3,3)，半径2√3。

## 二、大圆插值算法

**定义（大圆插值）**
给定球面上两点p1、p2，球心C，半径R，插值点：

    v1 = unit(p1 - C)
    v2 = unit(p2 - C)
    cos_theta = dot(v1, v2)
    theta = arccos(cos_theta)
    w1 = sin((1-t)*theta) / sin(theta)
    w2 = sin(t*theta) / sin(theta)
    p(t) = C + R * (w1*v1 + w2*v2)

性质：

1. 所有插值点在球面上，半径恒为R。
2. 沿大圆走，不经过球心。
3. 对径点（theta=π）时sin(theta)=0，大圆不唯一，需特殊处理。

## 三、实验一：大圆插值

### 非对径点

取(5,1,1)和(1,5,1)：

| t | 点 | 距球心 |
|---:|---|---:|
| 0 | (5.00, 1.00, 1.00) | 3.46 |
| 0.25 | (4.13, 1.87, -0.08) | 3.46 |
| 0.5 | (3.00, 3.00, -0.46) | 3.46 |
| 0.75 | (1.87, 4.13, -0.08) | 3.46 |
| 1.0 | (1.00, 5.00, 1.00) | 3.46 |

半径恒定3.46，大圆插值成立。

### 对径点

取(5,1,1)和(1,5,5)：

| t | 结果 |
|---:|---|
| 0到1 | 标记"大圆不唯一" |

对径点时大圆不唯一，需特殊处理。

## 四、实验二：大圆vs直线

取(5,1,1)和(1,1,5)：

| t | 直线 | 大圆 | 大圆半径 |
|---:|---|---|---:|
| 0 | (5,1,1) | (5.0,1.0,1.0) | 3.46 |
| 0.25 | (4,1,2) | (4.13,-0.08,1.87) | 3.46 |
| 0.5 | (3,1,3) | (3.0,-0.46,3.0) | 3.46 |
| 0.75 | (2,1,4) | (1.87,-0.08,4.13) | 3.46 |
| 1.0 | (1,1,5) | (1.0,1.0,5.0) | 3.46 |

直线插值不保持半径，大圆插值保持半径。连续球体插值应走大圆。

## 五、实验三：双球体吸引力

### 路径观察

从新球体中宫(9,3,3)出发，加9，前8步：

| 步 | 位置 | 球体 |
|---:|---|---|
| 0 | (9,3,3) | new |
| 1 | (7,3,3) | new |
| 2 | (5,3,3) | old |
| 3 | (3,3,3) | old |
| 4 | (1,3,3) | old |
| 5 | (3,3,3) | old |
| 6 | (5,3,3) | old |
| 7 | (7,3,3) | new |

路径在(1,3,3)↔(3,3,3)↔(5,3,3)↔(7,3,3)↔(9,3,3)之间来回摆动。

### 50步停留统计

| 起点 | 旧停留 | 新停留 | 比例 |
|---|---:|---:|---:|
| 新球体中宫 | 25 | 25 | 1.0 |
| 旧球体中宫 | 25 | 25 | 1.0 |

结论：**双球体间是周期摆动，停留各半，不是锁死。**

### 修正59号结论

59号说"跨球后被锁在旧球体"，是30步观察窗口太短的误判。50步测试显示路径在两球体间周期摆动。

| 59号结论 | 61号修正 |
|---|---|
| 跨球后锁在旧球体 | 双球体间周期摆动 |
| 5多则锁死 | 5多则边界来回 |
| 吸引力=数量比 | 吸引力=路径结构 |

## 六、实验四：引力公式预测

### 5的数量

| 球体 | 5的数量 | 引力（5数量/27） |
|---|---:|---:|
| 旧球体 | 7 | 0.259 |
| 新球体 | 3 | 0.111 |
| 引力比 | 2.33 | |

### 预测vs实际

| 项 | 值 |
|---|---|
| 预测停留比（旧:新） | 2.33 |
| 实际停留比 | 1.0 |
| 预测是否成立 | **否** |

结论：引力公式预测失败。停留比例由路径结构决定，不由5数量决定。

## 七、核心发现

### 发现一：大圆插值算法成立

slerp算法保证所有插值点在球面上，半径恒定。对径点需特殊处理，标记"大圆不唯一"。

### 发现二：59号"锁死"结论需修正

30步观察窗口太短，看起来像锁死。50步显示路径在两球体间周期摆动，停留各半。

### 发现三：引力公式预测失败

5数量比2.33，实际停留比1.0。吸引力不是简单按数量分配，而是路径结构决定。

### 发现四：加9路径是边界摆动

路径在(1,3,3)↔(3,3,3)↔(5,3,3)↔(7,3,3)↔(9,3,3)之间来回，5的分布决定摆动范围，不决定停留比例。

## 八、结论

| 验证项 | 结果 |
|---|---|
| 大圆插值非对径 | 半径恒定3.46 |
| 大圆插值对径 | 标记"大圆不唯一" |
| 大圆vs直线 | 大圆保持半径，直线不保持 |
| 双球体停留 | 周期摆动，各半 |
| 引力公式 | 预测失败 |
| 59号"锁死"结论 | 需修正为"周期摆动" |

## 九、修订建议

1. 59号"锁死"结论修正为"周期摆动"。
2. 吸引力不是5数量比，是路径结构决定。
3. 大圆插值作为连续球体插值标准算法。
4. 双球体导航需考虑周期摆动，不是单向锁死。
