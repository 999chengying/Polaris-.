# Polaris 基础架构：四阶张量感受野与图网络子图连通性扩展

## 一、本文解决什么问题

在深度图神经网络（GNN）与视觉 Transformer 中，模型需要不同尺度的感受野（Receptive Field）来捕获从局部细节到全局宏观的特征。如何在固定大小的网格拓扑中，通过改变节点的连通方式和锚点（Anchor）分布，构建递进式的特征聚合结构，是网络架构设计的核心。
本文基于三维网格，提出**“四阶张量感受野模型”**。通过线性结构、面状结构与中心锚点的组合，构建出 24、28、32、36 四种递进的特征状态空间，为大模型的多尺度特征提取提供底层拓扑。

> **注：历史渊源**
> 本文所探讨的四种网络拓扑形态，深受中国古代经典《易经》中“四象”（老阴、少阳、少阴、老阳）理论的启发。
> 先哲以四象代表事物从微小萌发到宏大盘结的四个演化阶段。本文借其意，将四种拓扑形态对应为图网络中感受野由“一维线性”向“二维面状”，再向“带全局锚点”逐步扩张的四个工程阶段，以此致敬古代先哲对系统演化的洞察。

## 二、四阶张量模型定义

在三维坐标系中，以 8 个基础状态节点（顶点）为核心，我们定义如下四种递进拓扑：

### 1. 阶数一：线性基础子图（状态数 24）
- **结构**：一维链式/环式结构，无中心锚点。
- **数学构成**：8 个基础节点，每个节点包含 3 个自由度维度（或每条边 3 个状态），\(8 \times 3 = 24\)。
- **工程意义**：对应最基础的序列特征提取，类似于一维卷积或简单的线性注意力，计算量最小。

### 2. 阶数二：带锚点的一维扩展（状态数 28）
- **结构**：一维基础结构，引入 4 个局部中心节点（锚点）。
- **数学构成**：原有的 24 个状态，加上 4 个局部汇聚中心（\(24 + 4 = 28\)）。
- **工程意义**：在序列特征的基础上，增加了局部特征的汇聚池化（Pooling），提升了感受野的稳定性。

### 3. 阶数三：二维面状张量（状态数 32）
- **结构**：二维平面网格结构（如 2x2 网格布局），无全局中心锚点。
- **数学构成**：8 个基础节点扩展为 4 个面，每个面包含 8 个周边状态，\(4 \times 8 = 32\)。
- **工程意义**：适合处理图像局部块（Image Patches）或二维空间图结构，具备面状的邻域特征交互。

### 4. 阶数四：带全局锚点的二维扩展（状态数 36）
- **结构**：二维平面网格，引入 4 个全局/局部中心锚点。
- **数学构成**：原有的 32 个面状状态，加上 4 个核心锚点（\(32 + 4 = 36\)）。
- **工程意义**：系统的最强形态。面状特征在锚点处进行交叉融合（Cross-Attention），实现了感受野的全面覆盖与高维特征的深度重组。

## 三、代码实现

    FOUR_IMAGES = {
        "State_24": {"type": "linear", "vertices": 8, "anchors": 0, "total_states": 24},
        "State_28": {"type": "linear_anchored", "vertices": 8, "anchors": 4, "total_states": 28},
        "State_32": {"type": "2d_grid", "vertices": 32, "anchors": 0, "total_states": 32},
        "State_36": {"type": "2d_grid_anchored", "vertices": 32, "anchors": 4, "total_states": 36}
    }

    def get_receptive_field_info(state_name):
        """
        获取特定拓扑状态下的感受野配置。
        """
        if state_name in FOUR_IMAGES:
            info = FOUR_IMAGES[state_name]
            return f"拓扑类型: {info['type']} | 基础节点: {info['vertices']} | 锚点: {info['anchors']} | 总状态数: {info['total_states']}"
        return "未知状态"

    if __name__ == "__main__":
        for state in ["State_24", "State_28", "State_32", "State_36"]:
            print(get_receptive_field_info(state))

## 四、结论

| 阶数 | 历史启发 | 张量结构 | 状态总数 | 大模型网络应用 |
|---|---|---|---|---|
| 1 | 老阴 | 一维线性，无锚点 | 24 | 基础序列卷积 (1D Conv) |
| 2 | 少阳 | 一维线性，带 4 锚点 | 28 | 局部池化 / 层次化特征提取 |
| 3 | 少阴 | 二维面状，无锚点 | 32 | 视觉图像块交互 (2D Patch) |
| 4 | 老阳 | 二维面状，带 4 锚点 | 36 | 全局交叉注意力 (Cross-Attention) |
