# Polaris 工程规范：系统集成测试与鲁棒性验证清单

## 一、目的

本清单用于 Polaris 纯整数心智引擎在开发与迭代过程中的标准化验证。摒弃传统浮点神经网络通过“Loss 曲线”盲猜模型状态的做法，Polaris 引擎的每一次迭代，均需通过以下严格的离散代数与拓扑功能测试。

## 二、基础算术与状态机测试
- [ ] **进位级联测试**：验证 `(0, 0, 9) + 1` 是否能精准触发中宫状态机，并输出 `(0, 1, 0)`。
- [ ] **边界翻转测试**：验证绝对零点 `(0, 0, 0) - 1` 是否能在无借位空间下坍缩至 `(9, 9, 9)`。
- [ ] **逆元对称测试**：验证模10空间下，乘 3 后再乘 7，状态是否能 100% 无损耗还原。
- [ ] **幂积纠缠测试**：输入对称变量，验证系统是否能在 1-2 步内极速收敛至幂等元（5 或 6）。

## 三、拓扑路由与防幻觉测试
- [ ] **对称死锁测试**：输入 `(8, 3)` 和 `(2, 7)`，验证拓扑偏移定则（值+址）是否能成功打破相消，输出不同特征值。
- [ ] **过平滑防御测试**：在 TokamakConv 层输入全同质化特征（方差为 0），验证是否触发确定性相变算子，拉开特征差异。
- [ ] **极限环侦测测试**：模拟系统持续输出相同状态，验证元观测者（Meta-Observer）能否在阈值内预警，并执行强制归中（重置为 5）。

## 四、大模型端到端闭环测试
- [ ] **PTPP 投影测试**：向网关注入一段发散的浮点幻觉特征，验证系统能否将其校准回 `[7, 8, 9]` 的安全区间。
- [ ] **受限生成测试**：输入自然语言指令，验证解码器是否能严格遵守平仄、押韵与语法词性模板，杜绝“语无伦次”。
