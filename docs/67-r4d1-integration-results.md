# r=4 d=1 整合验证：全场景对比

## 一、这篇解决什么问题

在66号发现r=4 d=1优于r=2 d=2的基础上，把r=4 d=1整合进四阶段管道，全场景重跑，验证其通用性。

适合读者：对半径扩展、管道配置、全场景验证感兴趣的读者。

前提：27宫立方体，新旧赋值，中宫为5。

## 二、实验设计

| 配置 | r=2 d=2 | r=4 d=1 |
|---|---|---|
| 邻域大小 | 26 | 124 |
| 前瞻深度 | 2 | 1 |
| 单步复杂度 | O(26×候选²) | O(124) |

七组场景：旧中宫加9、旧顶点加9、旧z1加1、旧中宫加3、旧z1加3、新中宫加2、双球加9。

## 三、实验结果

| 场景 | r=2 d=2 | r=4 d=1 |
|---|---|---|
| 旧中宫加9 | 7发现，不卡 | 7发现，不卡 |
| 旧顶点加9 | 7发现，不卡 | 7发现，不卡 |
| 旧z1加1 | 3发现，不卡 | **6发现**，不卡 |
| 旧中宫加3 | 5发现，**卡死** | 4发现，**不卡** |
| 旧z1加3 | 6发现，**卡死** | 4发现，**不卡** |
| 新中宫加2 | 4发现，不卡 | 3发现，不卡 |
| 双球加9 | 7发现，跨8 | **11发现**，跨8 |

## 四、核心发现

### 发现一：r=4 d=1全面不卡死

旧中宫加3和旧z1加3在r=2 d=2下卡死，r=4 d=1全部解决。

### 发现二：旧z1加1发现翻倍

r=2 d=2发现3次，r=4 d=1发现6次。半径扩大后候选更多，雷达偏转更频繁。

### 发现三：双球加9发现大幅增加

r=2 d=2发现7次，r=4 d=1发现11次。跨球场景受益最大。

### 发现四：新中宫加2是唯一r2d2发现更多的场景

r=2 d=2发现4次，r=4 d=1发现3次。但r=4 d=1平均级别3.0，高于r=2 d=2的2.5。

### 发现五：不卡死场景两者持平

旧中宫加9、旧顶点加9两者完全相同。r=4不改变已稳定的路径。

## 五、结论

| 验证项 | 结果 |
|---|---|
| 卡死场景 | r=4 d=1全部解决 |
| 发现次数 | r=4 d=1多数场景更多 |
| 平均级别 | 多数场景持平或更高 |
| 双球场景 | r=4 d=1显著更优 |

## 六、推荐配置

> **默认配置：r=4 d=1。**  
> 不卡死，发现多，双球场景受益最大。新赋值场景可酌情用r=2 d=2。
