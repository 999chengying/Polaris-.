# 动态阈值：从固定决策到自适应决策

## 一、这篇解决什么问题

在54号四阶段管道的基础上，把决策阶段的固定阈值升级为动态阈值。分析固定阈值的卡死问题、动态阈值v1的失效原因、动态阈值v2的修正机制，并给出实验验证。

适合读者：对决策机制、自适应阈值、防卡死策略感兴趣的读者。

前提：27宫立方体，旧赋值为主，中宫为5。

## 二、固定阈值的局限

54号的决策规则：

    若 最高级别 >= 意图阈值：
        选定最高级别对象
    否则：
        继续原路径，不偏转

固定阈值对照：

| 阈值 | 意图 | 行为 |
|---:|---|---|
| 1 | 恒久意图 | 只接受1级 |
| 2 | 感应意图 | 接受2级以上 |
| 3 | 连接意图 | 接受3级以上 |
| 4 | 不偏转 | 纯惯性 |

固定阈值的问题：

1. 阈值1：找不到1级时卡死；
2. 阈值2：找不到1、2级时卡死；
3. 阈值3：容易找到但级别低；
4. 阈值4：从不主动，零发现。

核心矛盾：**挑剔则卡死，宽松则低质。**

## 三、动态阈值v1

v1引入三因素：

| 因素 | 含义 | 方向 |
|---|---|---|
| 饥饱 | 距上次发现的步数 | 越饿越宽 |
| 距离 | 距中宫距离 | 越远越急 |
| 成功 | 最近发现的级别 | 发现低级后调整 |

v1公式：

    T = clamp(2 + 饥饱 + 距离 + 成功, 1, 3)

v1的问题：饥饿机制要3步才触发放宽，但路径可能2步就断。**放宽来不及。**

实验验证：旧赋值从顶点出发加9，v1在顶点起点卡死，与固定阈值1、2相同。

## 四、动态阈值v2

v2新增即时因子：

    扫描后，若当前半径内最高级别 < T，立即将T降到该级别。

v2完整公式：

    T = 2
    若 since >= 3: T += 1
    若 since >= 6: T += 1
    若 dist >= 3.5: T += 1
    若 last == 3: T -= 1
    若 last == 1: T += 1
    T = clamp(T, 1, 3)
    若 cur_max > 0 且 cur_max < T: T = cur_max

关键新增：**断后偏转**。路径即将断时，若扫描到任何级别，立即接受，不卡死。

v2的行为：

| 场景 | v2动作 |
|---|---|
| 扫描到1级 | T保持或降为1，挑剔 |
| 扫描到3级 | T降为3，立即接受 |
| 连续无发现 | T逐步升到3 |
| 路径即将断 | 断后偏转，接受当前最高级 |

## 五、实验验证

### 实验一：旧赋值，中宫起点，加9

| 模式 | 发现 | 平均级别 | 卡死 | 序列 |
|---|---:|---:|---:|---|
| 固定T=1 | 1 | 1.0 | 0 | [1] |
| 固定T=2 | 1 | 1.0 | 0 | [1] |
| 固定T=3 | 8 | 2.25 | 0 | [1,3,3,2,1,3,3,2] |
| 动态v2 | 6 | 2.17 | 0 | [1,3,3,2,1,3] |

动态v2介于T=1和T=3之间：先找到1级，后放宽，再挑剔，再放宽。发现6次，平均级别2.17。

### 实验二：旧赋值，顶点起点，加9

| 模式 | 发现 | 平均级别 | 卡死 | 序列 |
|---|---:|---:|---:|---|
| 固定T=1 | 2 | 2.0 | 0 | [3,1] |
| 固定T=2 | 2 | 2.0 | 0 | [3,1] |
| 固定T=3 | 8 | 2.25 | 0 | [3,1,3,2,1,3,3,2] |
| 动态v2 | 8 | 2.25 | 0 | [3,1,3,2,1,3,2,3] |

动态v2与固定T=3持平：8次发现，2.25平均级别，不卡死。序列更灵活。

### 实验三：v2轨迹关键步

| 步 | 位置 | T | 扫描 | 动作 |
|---:|---|---:|---|---|
| 1 | (1,1,3) | 2 | L3 | 断后偏转L3 |
| 3 | (5,1,3) | 1 | L1 | 偏转L1 |
| 4 | (3,3,1) | 3 | L3 | 偏转L3 |
| 8 | (3,3,5) | 2 | L2 | 偏转L2 |

T在1和3之间波动，系统在挑剔和放宽之间动态调整。

## 六、核心结论

1. 固定阈值无法兼顾挑剔和防卡死。
2. 动态阈值v1只看历史，来不及放宽。
3. 动态阈值v2加入即时因子和断后偏转，成功防卡死。
4. v2在顶点起点不劣于固定T=3，在中宫起点更挑剔。
5. v2的核心：**当前能扫到什么级别，就先接受什么级别，不卡死是第一优先级。**

## 七、v2的定位

| 场景 | 固定T=1 | 固定T=3 | 动态v2 |
|---|---|---|---|
| 1级始终可及 | 够用 | 发现多但低质 | 先挑剔后放宽 |
| 1级不可及 | 卡死 | 发现多 | 不卡死，发现多 |
| 1级时有时无 | 卡死 | 发现多 | 不卡死，灵活 |

> **动态阈值不是提速工具，是防卡死工具。**

## 八、可验证推论

1. v2在任意起点均不卡死。
2. v2的发现次数不低于固定T=3。
3. v2的平均级别不低于固定T=2。
4. v2的T值在1到3之间波动。
5. 断后偏转是v2不卡死的关键机制。

## 九、与54号的关系

54号四阶段管道：

| 阶段 | 54号 | 55号升级 |
|---|---|---|
| 探测 | 固定半径 | 不变 |
| 评估 | 固定分级 | 不变 |
| 决策 | 固定阈值 | **动态阈值v2** |
| 执行 | 固定规则 | 不变 |

55号只改决策阶段，其余三阶段不变。
