# 三条链的转移路径矩阵

## 一、这篇解决什么问题

验证147、258、369三条链在数字层的转移路径。

适合读者：对数字链、图结构、路径分析感兴趣的读者。

前提：邻接关系从结构推导，不手工指定。

## 二、邻接关系推导原则

1. 阳链正向：1→2→4→7→1；
2. 阴链正向：9→8→6→3→9；
3. 258链：5→8；
4. 反向；
5. 合十对：1-9、2-8、3-7、4-6。

由此得到每个数字的邻居。
