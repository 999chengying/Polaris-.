# 先验强度扫描：倒U形与边界

## 一、这篇解决什么问题

验证先验强度与模型外推能力的关系。

适合读者：对先验注入、外推能力、模型泛化感兴趣的读者。

前提：任务为sin函数外推，训练集[-1,1]，测试集[1,3]。

## 二、实验设计

输入x，输出sin(x)。

训练只覆盖[-1,1]，测试为[1,3]。

对比七种先验配置：

| 配置 | 输入维度 |
|---|---|
| 只有x | 1 |
| x+sin | 2 |
| x+sin+cos | 3 |
| x+sin+cos+x² | 4 |
| x+sin+cos+x²+x³ | 5 |
| 只sin+cos | 2 |
| 只sin+cos+sin2+cos2 | 4 |

## 三、实验结果

| 配置 | 参数量 | 训练误差 | 测试误差 |
|---|---:|---:|---:|
| 只有x | 49 | 0.0015 | 0.4997 |
| x+sin | 65 | 0.0005 | 0.2339 |
| x+sin+cos | 81 | 0.0046 | 0.1291 |
| x+sin+cos+x² | 97 | 0.0007 | 0.2906 |
| x+sin+cos+x²+x³ | 113 | 0.0030 | 1.1505 |
| 只sin+cos | 65 | 0.0012 | 0.1440 |
| 只sin+cos+sin2+cos2 | 97 | 0.0027 | 1.1041 |

## 四、倒U形

测试误差随先验强度先降后升：

只有x → x+sin → x+sin+cos（最优）→ 加高阶项（变差）

无先验：无法外推。
适度先验：效果最好。
过度先验：效果更差。

先验强度呈倒U形：无则不成，过则有害。

## 五、两个独立发现

### 发现一：高阶项有害

x²、x³在训练集[-1,1]内数值小，在测试集[1,3]内数值爆炸。

高阶项在训练集外发散。

### 发现二：高频先验有害

只sin+cos测试误差0.1440。
只sin+cos+sin2+cos2测试误差1.1041。

基频先验好，高频先验差。

高频成分让网络在训练集内过拟合，出训练集即乱。

## 六、与九宫结构的呼应

先验与基础信息，如同阴阳，需平衡。

| 先验状态 | 阴阳 | 效果 |
|---|---|---|
| 无先验 | 纯阴 | 不成 |
| 适度先验 | 阴阳平衡 | 最优 |
| 过度先验 | 纯阳 | 有害 |

恰好处方为道，过与不及皆非。

## 七、边界声明

本实验只针对sin函数外推任务。

结论不能直接外推到所有任务。

可定义、可推导、可检验；有用则留，无用则弃。

## 八、口诀

先验强度倒U形，无则不成过则倾。
基础信息不可弃，适度周期最相应。
高阶高频皆有害，训练集外即发疯。
阴阳平衡方为道，恰好匹配是真经。
