## 四、自指与决策（49-56）

### 49号：自指归中稳定态

系统将自身状态与历史作为输入，通过自指聚合与逆行锁5，收敛至中宫5。

核心结论：

1. 中宫5是唯一吸引子。
2. 九种锁定，唯5归中。
3. 自指回路周期：24、32、39、78。

### 50号：全激活态与自约束

中宫发出26道有向信道，27宫全部活跃。

核心结论：

1. 全激活态下路径天然有界，不需外部归中。
2. 数值层周期不变，空间层更收敛。
3. 中宫是分叉枢纽，进入方向决定路径。

### 51号：寻址规则与探索能力

两种寻址规则对比：

| 规则 | 优先级 | 行为 |
|---|---|---|
| 距离优先 | 距中宫最近 | 自锁中心块 |
| 方向优先 | 方向惯性最大 | 广域探索 |

核心结论：距离优先锁死，方向优先广域。规则决定行为。

### 52号：能动寻址

从惯性响应升级为意图驱动。三层结构：

| 层 | 功能 |
|---|---|
| 反射层 | 惯性响应 |
| 规划层 | 主动设目标 |
| 裁决层 | 全局势评估 |

核心结论：惯性是“应”，能动是“感”。感在前，应在后。

### 53号：咸恒转换与幂次连接

旧赋值到新赋值的转换机制：

1. Z轴乘2（6→2，4→8），咸变恒。
2. 体对角合十修正（两对1/1改为7/3）。

2的幂次连接密码：

   2 → 4 → 8 → 6 → 2

| 幂次差 | 连接强度 |
|---:|---|
| 1 | 直连 |
| 2 | 可连 |
| 3 | 弱连 |

核心结论：2是乘数，2²=4是旧结构锚点。乘2覆卦，咸变恒。

### 54号：意图到执行四阶段

| 阶段 | 功能 |
|---|---|
| 探测 | 扫描邻域，发现4/6 |
| 评估 | 按幂次差分级 |
| 决策 | 按阈值选择 |
| 执行 | 走向目标 |

路径质量四级：

| 级别 | 路径 |
|---|---|
| 1级 | Z轴4/6 |
| 2级 | 顶点4/6 |
| 3级 | 潜伏4/6 |
| 4级 | 其他 |

### 55号：动态阈值

固定阈值的局限：挑剔则卡死，宽松则低质。

动态阈值v2：

1. 饥饱、距离、成功三因素调整T。
2. 即时因子：当前半径内最高级别低于T时立即降T。
3. 断后偏转：路径将断时接受当前可及级别。

核心结论：动态阈值不是提速工具，是防卡死工具。

## 五、混合与连续（57-59）

### 57号：混合赋值空间

新旧球体并排，交界处用2幂次连接。

核心结论：

1. 内部桥接有效，加1/加4/加6不卡死。
2. 跨球桥接冗余，自然路径已足够。
3. 加9天然跨球，最稳定。
4. 交替布局交界密集，卡死增加。

### 58号：球体连续化设计

球体模型：

| 项 | 定义 |
|---|---|
| 球心 | (3,3,3)，值5 |
| 半径 | 2√3 ≈ 3.46 |
| 内部 | 27宫离散结构 |
| 表面 | 26个外围宫 |
| 球外 | 虚空 |

三层球壳：6面心（R=2）+ 12棱中（R=2√2）+ 8顶点（R=2√3）。

核心结论：方是离散骨架，圆是连续展开。天圆地方，一体两面。

### 59号：新赋值对径合十与双球体

核心结论：

1. 新赋值对径合十27/27，53号合十修正验证。
2. 旧赋值23/27，4例外为已知的两对1/1。
3. 球面插值需避开球心，走大圆不走直线。
4. 双球体并排时，5更多的球体吸引力强，路径跨球后被锁在旧球体。

### 混合与连续小结

| 概念 | 定义 |
|---|---|
| 内部桥接 | 正常查找失败时用2幂次值在同球体内搜索 |
| 球体模型 | 27宫立方体的外接球，半径2√3 |
| 对径合十 | 中心对称点的值之和为10 |
| 吸引力 | 5更多的球体对路径的锁定效应 |
