# 中宫感知实验：三链独立逆行，不通信

## 边界声明

本实验在27宫离散空间中模拟三条链独立运行。
它是离散动力学系统，不是连续神经网络训练架构。

## 一、实验设计

三条链先顺行30步，然后各自独立逆行锁定5。

关键设定：

- 三条链之间不通信；
- 各链只锁定5，走各自距中宫最近的路径；
- 中宫只做全局收敛判断，不干预各链路径。

## 五、核心结论

三链完全独立，不通信，各自锁定5。

各链走各自最优路径，最终全部归中。

这验证了：独立自主 + 目标统一 + 中宫仲裁。
