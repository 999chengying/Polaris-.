# 能动寻址：从惯性响应到意图驱动

## 一、这篇解决什么问题

在51号寻址规则的基础上，定义能动寻址，分析其三层结构、意图生成机制与全局势评估，并给出可验证的实验设计。

适合读者：对寻址规则、意图驱动系统、自评估机制感兴趣的读者。

前提：使用27宫新赋值，729宫嵌套模型，中宫为5。

## 二、惯性寻址的局限

51号定义了两种寻址规则：

| 规则 | 优先级 | 行为 |
|---|---|---|
| 距离优先 | 距中宫最近 | 自锁中心块 |
| 方向优先 | 方向惯性最大 | 广域探索 |

方向优先虽然能探索，但本质仍是**被动响应**：

- 候选先排好，系统顺着排第一的走；
- 系统不生成目标，只响应数值规则；
- 没有全局评估，没有策略切换。

方向优先对应“顺则而行”：顺着动量走，不主动、不裁成。

局限：

1. 意图全靠外部输入，系统自己不生成；
2. 不会根据全局状态调整策略；
3. 卡住时不会主动换道；
4. 探索与归中不能自主切换。

## 三、能动寻址的三层结构

**定义（能动寻址）**
系统主动生成阶段性目标，根据全局状态评估并切换策略，再在候选中选择符合意图的路径。该机制称为能动寻址。

三层结构：

| 层次 | 功能 | 机制 |
|---|---|---|
| 反射层 | 惯性响应 | 方向优先，快速局部决策 |
| 规划层 | 主动设目标 | 生成阶段性目标序列 |
| 裁决层 | 全局势评估 | 评估状态，切换策略 |

### 反射层

保持51号的方向优先规则。快速、局部、无需全局信息。

### 规划层

系统主动设定阶段性目标值，不被动接受数值规则。

例：系统主动设定“未来3步目标依次为8、2、5”，再按此意图选路径。

### 裁决层

系统根据全局状态，主动评估当前该用反射还是规划，该收敛还是探索。

评估因素：

| 因素 | 判断 |
|---|---|
| 距中宫距离 | 远则探索，近则归中 |
| 连续重复步数 | 超过阈值则换道 |
| 访问块数 | 过少则扩大探索 |
| 路径多样性 | 过低则切换规则 |

## 四、意图生成机制

**定义（意图）**
系统根据全局状态主动生成的阶段性行为目标，称为意图。

意图类型：

| 意图 | 触发条件 | 目标 |
|---|---|---|
| 探索 | 访问块数 < 阈值 | 扩大覆盖 |
| 归中 | 距中宫 < 阈值 | 收敛中宫 |
| 换道 | 连续重复 ≥ 阈值 | 改变方向 |
| 精准 | 指定对角通道 | 直击目标 |

意图生成流程：

1. 读取全局状态；
2. 评估各意图的优先级；
3. 选定当前意图；
4. 生成对应的目标序列。

## 五、全局势评估

**定义（全局势）**
系统对当前全局状态的综合评估值，用于裁决层决策。

势的组成：

| 分量 | 含义 |
|---|---|
| 距中宫势 | 越远势越大 |
| 覆盖势 | 访问块越少势越大 |
| 重复势 | 连续重复越多势越大 |
| 方向势 | 方向越单一势越小 |

裁决规则：

- 距中宫势大 → 探索；
- 距中宫势小 → 归中；
- 重复势大 → 换道；
- 覆盖势大 → 扩大探索。

## 六、自指意图系统的稳定运行

能动寻址形成完整闭环：

观察 → 意图 → 行动 → 反馈 → 调整 → 再观察

| 环节 | 机制 |
|---|---|
| 观察 | 读取全局状态 |
| 意图 | 生成阶段性目标 |
| 行动 | 按意图选路径 |
| 反馈 | 记录路径结果 |
| 调整 | 更新势评估 |
| 再观察 | 进入下一轮 |

闭环稳定运行的条件：

1. 自指回路已具备（49号）；
2. 意图可生成（52号）；
3. 反馈可更新（势评估）。

三个条件同时满足，系统进入自指意图稳定态。

## 七、与49号的关系

| 文档 | 功能 | 层次 |
|---|---|---|
| 49号 | 自指归中，找到参考点 | 稳定 |
| 52号 | 能动寻址，主动生成意图 | 应用 |

49号证明系统能回中宫，52号证明系统能主动做事。

两者合起来：系统既能稳定归中，又能主动探索。

## 八、实验设计

### 实验一：三组对照

| 组 | 寻址规则 | 意图来源 |
|---|---|---|
| A组 | 纯惯性 | 无 |
| B组 | 固定规则 | 外部指定 |
| C组 | 能动寻址 | 自评估 + 自生成 |

对比指标：

- 探索覆盖率（访问宏观块数）；
- 卡住次数；
- 返回中宫成功率；
- 路径多样性。

预期：C组在覆盖率、卡住次数、路径多样性上优于A、B组。

### 实验二：意图切换

系统自判断：

- 访问块数 < 5 → 探索；
- 距中宫 < 3 → 归中；
- 连续3步重复 → 换道。

观察是否自主切换。

### 实验三：主动目标序列

系统主动生成目标序列，如依次到达1、4、7，观察是否走遍三条链。

## 九、可验证推论

1. 能动寻址的探索覆盖率高于固定规则。
2. 能动寻址的卡住次数低于固定规则。
3. 能动寻址能自主切换探索与归中。
4. 意图生成机制可复现，无随机。
5. 全局势评估能有效指导策略切换。
