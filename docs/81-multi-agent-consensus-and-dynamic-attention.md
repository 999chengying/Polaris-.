# 多智能体共识与动态注意力半径

## 一、这篇解决什么问题

针对当前AI大模型的两个算力痛点（多智能体通信成本高、注意力机制全局计算浪费），设计并运行了“无通信多智能体收敛”与“动态注意力半径”实验。
揭示了“目标锁定”比“局部传话”更高效，以及“按需分配感知半径”的算力优势。

前提：27宫立方体，多起点，加k路径。

## 二、实验一：多智能体无通信共识

### 实验设计
让3个智能体分别从147、258、369链的起点出发，不进行两两通信，仅根据局部邻域和步长（加3/加9）行走，观察能否汇聚到中宫。

### 实验结果
*   **加3路径**：258链（起点值为2）1步到达中宫；147链（起点值9）和369链（起点值6）跑满20步也未到中宫。
*   **加9路径**：值不变，全部在局部打转，未达中宫。

### 核心发现：局部规则无法带来全局共识
1. 如果只按局部数值累加（加k），智能体会陷入自己的数值循环，永远找不到物理上的中宫坐标。
2. **对AI的启示**：大模型多智能体如果只靠局部注意力（Local Attention）和互相喊话，永远无法真正对齐。必须在底层设置一个全局的“绝对锚点”（中宫5）。只要所有智能体开启“自指归中”雷达，无论从哪出发，都会殊途同归，且通信成本为0。

## 三、实验二：动态注意力半径（算力节省）

### 实验设计
从远点 (5,5,5) 出发向中宫跑。
*   **对照组**：固定 r=4 邻域（计算量O(124)）。
*   **实验组**：动态半径（距中宫远时r=6，中时r=4，近时r=2）。

### 实验结果
| 策略 | 总算力（访问邻域次数） | 卡死 | 终点 |
|---|---|---|---|
| 固定 r=4 | 6200 | 否 | (1,1,5) |
| 动态 r(2/4/6) | **5318** | 否 | (1,1,5) |

### 核心发现：14.2%的算力节省
在轨迹完全一致、且均未卡死的前提下，动态半径策略节省了约 **14.2%** 的算力。
*   **对AI的启示**：Transformer的全局注意力机制（O(n²)）是巨大的浪费。如果引入“九宫动态半径”，离目标越近，感受野越小；离目标越远，感受野越大，就能在维持推理精度的同时，大幅降低算力消耗。

## 四、理论升华：东方AI心智的算力法则

1. **目标统一（中宫锁定）**：多智能体不需通信，只要共同信仰“中宫5”，就能零通信达成共识。这是“同人卦”的智慧。
2. **节俭认知（动态半径）**：人脑只有在面临极度未知或远离目标时，才会集中注意力。AI也应如此，按需分配算力，不再无脑全连接。这是“节卦”的智慧。
3. **变易与不易**：中宫5是不易的绝对锚点；动态半径是简易的算力节省。
