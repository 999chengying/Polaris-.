## 四、自指与决策（49-56）

### 49号：自指归中稳定态

系统将自身状态与历史作为输入，通过自指聚合与逆行锁5，收敛至中宫5。

核心结论：

1. 中宫5是唯一吸引子。
2. 九种锁定，唯5归中。
3. 自指回路周期：24、32、39、78。

### 50号：全激活态与自约束

中宫发出26道有向信道，27宫全部活跃。

核心结论：

1. 全激活态下路径天然有界，不需外部归中。
2. 数值层周期不变，空间层更收敛。
3. 中宫是分叉枢纽，进入方向决定路径。

### 51号：寻址规则与探索能力

| 规则 | 优先级 | 行为 |
|---|---|---|
| 距离优先 | 距中宫最近 | 自锁中心块 |
| 方向优先 | 方向惯性最大 | 广域探索 |

核心结论：距离优先锁死，方向优先广域。规则决定行为。

### 52号：能动寻址

从惯性响应升级为意图驱动。三层结构：反射层、规划层、裁决层。

核心结论：惯性是“应”，能动是“感”。感在前，应在后。

### 53号：咸恒转换与幂次连接

旧赋值到新赋值的转换机制：

1. Z轴乘2（6→2，4→8），咸变恒。
2. 体对角合十修正（两对1/1改为7/3）。

2的幂次连接密码：

    2 → 4 → 8 → 6 → 2

| 幂次差 | 连接强度 |
|---:|---|
| 1 | 直连 |
| 2 | 可连 |
| 3 | 弱连 |

核心结论：2是乘数，2²=4是旧结构锚点。乘2覆卦，咸变恒。

### 55号：动态阈值

固定阈值的局限：挑剔则卡死，宽松则低质。

动态阈值v2：

1. 饥饱、距离、成功三因素调整T。
2. 即时因子：当前半径内最高级别低于T时立即降T。
3. 断后偏转：路径将断时接受当前可及级别。

核心结论：动态阈值不是提速工具，是防卡死工具。

## 五、混合与连续（57-61）

### 57号：混合赋值空间

新旧球体并排，交界处用2幂次连接。

核心结论：

1. 内部桥接有效，加1/加4/加6不卡死。
2. 跨球桥接冗余，自然路径已足够。
3. 加9天然跨球，最稳定。
4. 交替布局交界密集，卡死增加。

### 58号：球体连续化

球体模型：

| 项 | 定义 |
|---|---|
| 球心 | (3,3,3)，值5 |
| 半径 | 2√3 ≈ 3.46 |
| 内部 | 27宫离散结构 |
| 表面 | 26个外围宫 |
| 球外 | 虚空 |

三层球壳：6面心（R=2）+ 12棱中（R=2√2）+ 8顶点（R=2√3）。

核心结论：方是离散骨架，圆是连续展开。天圆地方，一体两面。

### 59号：新赋值对径合十与双球体

核心结论：

1. 新赋值对径合十27/27，53号合十修正验证。
2. 旧赋值23/27，4例外为已知的两对1/1。
3. 球面插值需避开球心，走大圆不走直线。
4. 双球体并排时，路径在两球体间周期摆动。

### 61号：大圆插值与双球体吸引力

核心结论：

1. 大圆插值（slerp）半径恒定，对径点需特殊处理。

## 六、寻址优化与落地（62-70）

### 62号：意图到执行管道Python模块

### 63号：前瞻寻址

加3 z=1卡死诊断与修正。

根因：方向惯性把路径引向死胡同。

修正：一步前瞻，优先选“下一步还有候选”的候选。

结果：加3 z=1进入三点循环，不卡死。加1仍卡死。

### 64号：前瞻与历史

“既要前瞻，又要历史”的自指选址原则。

核心结论：

1. 182次预测中三种原则全部一致。
2. 前瞻和历史通常一致，只在关键岔路处分化。
3. 纯历史会卡死，前瞻是防卡死的必要条件。

### 65号：加1卡死多方案对比

| 方案 | 卡死 |
|---|---|
| 深度1 r=2 | 是 |
| 深度2 r=2 | 否 |
| 深度3 r=2 | 否 |
| r=4 | 代码bug |

核心结论：深度2解决加1卡死。r=4方案失败是neighbors bug。

### 66号：半径扩展修正

修正neighbors后重跑：

| 路径 | r=2 d=2 | r=4 d=1 |
|---|---|---|
| 加1 z=1 | 二循环 | 9步全循环 |
| 加1 中宫 | 二循环 | 9步全循环 |
| 加3 中宫 | 卡死 | 三点循环 |

核心结论：r=4 d=1优于r=2 d=2，半径扩展比深度前瞻更有效。

### 67号：r=4 d=1整合验证

全场景对比：

| 场景 | r=2 d=2 | r=4 d=1 |
|---|---|---|
| 旧z1加1 | 3发现 | 6发现 |
| 旧中宫加3 | 卡死 | 不卡 |
| 双球加9 | 7发现 | 11发现 |

核心结论：r=4 d=1全面不卡死，双球场景受益最大。

### 68号：r=4下阈值对比

| 场景 | T=3 | 动态v2 |
|---|---|---|
| 旧中宫加9 | 8发现 | 7发现 |
| 双球加9 | 14发现 | 11发现 |

核心结论：r=4下不卡死，动态阈值无用武之地，固定T=3发现最多。
