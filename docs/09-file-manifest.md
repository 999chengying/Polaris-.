# Polaris 资源清单：核心模块依赖与系统架构映射

## 一、工程目录结构

本清单定义了 Polaris 引擎的核心代码库与文档库的依赖映射关系。

### 1. `src/` (核心代码库)
- `v2_arithmetic.py`：连续值小模的四则运算、状态机进位与模10群演化。
- `v3_tokamak.py`：三维双墙约束、TokamakConv 图卷积与降维相变算子。
- `v4_moe_router.py`：3D-Cross MoE 分布式路由、空间偏置与三维并发引擎。
- `v5_ptpp_gateway.py`：大模型浮点投影网关、因果干预与元观测者自纠偏。
- `v6_llm_decoder.py`：纯整数词表采样、受限语法状态机与端到端文本生成。

### 2. `docs/` (理论白皮书与规范)
- `00-index.md`：全局目录索引。
- `01-07`：V1 基础三维拓扑映射与网络链路基础。
- `docs-v2` 至 `docs-v5`：核心引擎与防幻觉网关的演进史。

## 二、核心依赖与运行环境
由于引擎采用纯整数与离散代数构建，完全剥离了浮点张量运算框架：
- **软依赖**：Python 3.8+（用于原型验证与算法演示）。
- **硬依赖**：无（不依赖 PyTorch/TensorFlow，可直译为 C 或 Verilog 并在 FPGA 上综合）。
