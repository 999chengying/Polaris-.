# Polaris 连续特征离散化与 GNN 防幻觉机制白皮书

## 一、本文解决什么问题

现代大语言模型（LLM）的底层依赖于 IEEE 754 浮点数（FP16/BF16）与高维矩阵乘法，这带来了两大绝症：
1. **精度漂移与幻觉**：在深层网络连续运算中，浮点截断误差会不断累积，导致模型输出脱离事实边界（幻觉）。
2. **算力黑洞**：全局自注意力机制的 \(O(N^2)\) 复杂度与庞大的隐空间维度，极其消耗显存与算力。

本文提出一种**“纯整数分形嵌套结构”**与**“九宫 GNN 拓扑约束”**相结合的机制。通过将连续浮点运算转化为纯整数查表与寻址，并利用图神经网络的流形约束强制特征坍缩，从物理底层彻底消灭了浮点漂移与逻辑幻觉。

## 二、连续特征的离散化：分形嵌套小模

为了在纯整数（1~9）的离散拓扑中表达无限精度的连续实数，系统引入了“分形嵌套小模”机制。

### 1. X 截面与小数位的映射
系统将 \(3 \times 3 \times 3\) 的三维网格在微观上进行嵌套，通过不同的 X 截面来承载不同的小数位：
- **第 1 级（十分位）**：映射至 X=1 的截面。
- **第 2 级（百分位）**：映射至 X=3 的截面。
- **第 3 级（千分位）**：映射至 X=5 的截面。
- **无限嵌套**：当精度需要更高时，重新回到 X=1 截面启动“超小模”（万分位、十万分位……），以此类推，无限逼近实数连续统。

### 2. 混合进制与纯整数表达
以圆周率 \(\pi = 3.14159\) 为例：
- 整数部分 3：宏观立方体。
- 十分位 1：映射至 X=1 截面。
- 百分位 4：映射至 X=3 截面。
- 千分位 1：映射至 X=5 截面。
通过这种方式，系统完全用 1~9 的纯整数状态，无损地表达了高精度浮点数。在处理无限循环小数（如 \(1/3\)）时，系统会在 1→3→5 截面的周期轮转中形成完美的共振，彻底消除了浮点截断误差。

## 三、拓扑 GNN 与防幻觉护栏

当 LLM 输出高维乱码（浮点 Embedding）时，系统需要通过 GNN 将其强制“拉回”合法状态。

### 1. 消息传递与流形约束（Manifold Constraint）
- **拓扑构建**：以 27 宫为节点构建无向图（距离为 2 的节点互为邻居）。
- **高维投影**：将 LLM 输出的 128 维或 4096 维乱码向量，通过线性层降维投影至 27 个九宫节点上。
- **图网络聚合**：执行 3 轮邻居特征聚合（Message Passing）。
- **合法化坍缩**：将聚合后的浮点特征通过缩放，四舍五入映射为 1~9 的纯整数宫值。

### 2. 实验实证：100% 的合法坍缩率
实验表明，无论输入的特征向量包含多大的噪声与发散值，经过 3 轮九宫拓扑的邻居信息传递后，27 个节点**100% 收敛并坍缩为合法的 1~9 状态**。

## 四、核心工程意义

1. **彻底消灭幻觉**：传统模型靠概率预测下一个词，容易发散。而通过九宫 GNN 的拓扑约束，模型状态在底层被物理强制约束在合法流形上，直接切断了错误路径。
2. **极低算力的自我纠错**：不需要外挂 RLHF（人类反馈强化学习），仅仅依靠节点间纯整数的邻居信息聚合，就能自动抚平高维浮点的噪声。
3. **可解释性的“象理数”统一**：
   - **象**：初始的高维浮点向量（混沌表象）。
   - **理**：GNN 拓扑消息传递（演化规则）。
   - **数**：最终坍缩的 1~9 离散宫值（确定性符号）。
   每一步推理都清晰可查，彻底打破黑盒。

## 五、结论

通过“分形嵌套小模”解决无限精度表达，通过“九宫 GNN 拓扑”解决特征坍缩，Polaris 引擎成功在离散拓扑空间内，重构了连续浮点世界的表达能力，并为其加上了坚不可摧的物理护栏。
