# 三链一宫：从九宫路径到AI架构的概念映射

## 边界声明

本文是概念映射，不是可直接训练的网络架构。
它验证的是顺逆规则在离散状态空间中的收敛性，
而非替代反向传播的连续优化方法。

## 一、核心映射

| 九宫结构 | AI对应 |
|---|---|
| 27宫 | 离散状态空间 |
| 三条链 | 三条处理通道 |
| 中宫5 | 目标表示 |
| 顺行 | 前向执行，按序列走 |
| 逆行 | 目标对齐，逐步归中 |
| 锁定5 | 目标锁定 |
| (3,3,3) | 稳定态 |

## 二、三链分工

| 链 | 数字 | 功能 |
|---|---|---|
| 147 | 1,4,7 | 特征保持 |
| 258 | 2,5,8 | 特征交换 |
| 369 | 3,6,9 | 特征收敛 |

## 三、顺行规则

按帝5序列循环：3→5→9→5→6→5→3

每一步：
1. 目标数字对应一个状态；
2. 选方向惯性最大的候选；
3. 距离最近优先；
4. 字典序最小兜底。

## 四、逆行规则

1. 锁定目标5；
2. 每步找最近的5；
3. 逐步归中。

逆行不传梯度，只做目标对齐。

## 五、能验证什么

1. 顺逆规则在离散空间中的收敛性；
2. 锁定5的唯一性；
3. 逆行归中的线性规律；
4. 多次循环的可重复性。

## 六、不能做什么

1. 替代反向传播的连续优化；
2. 直接训练神经网络参数；
3. 处理连续高维输入；
4. 与Transformer等架构直接对接。

## 七、下一步方向

1. 把顺逆规则作为推理调度器；
2. 把中宫5作为目标表示；
3. 在离散决策任务上做实验。
